## 3. 验证结论与适用范围

[M0-01 验证记录](../validation/M0-01-environment.md)记载：在 Ubuntu 22.04.5 / x86-64 基线机器上，使用 GCC 11.4.0、CMake/CTest 3.22.1、Ninja 1.10.1，Debug 与 Release 干净构建均成功，CTest 均为 **6/6 通过**；Release 启用了 `-Werror`。

[M0-02 验证记录](../validation/M0-02-mujoco.md)记载：MuJoCo 4.0.1 使用 GCC 12.3.0 源码构建并安装成功；Terra Debug 与 Release 均为 **9/9 通过**。`ldd terra_headless` 确认 `libmujoco` 通过 RPATH 从本地安装目录加载，且没有图形库依赖。配置和运行时版本核对、缺失依赖报错、版本不匹配报错及公共头边界检查均通过。

这些结果证明工程骨架和 MuJoCo 依赖可以在基线机器上构建、链接、装载和运行探针，不能证明模型加载、无图形物理仿真、接触精度、传感器或性能达标。本次提交前仅执行文档与差异静态检查，没有重新编译或运行 CTest。

仍需保留的验证限制：

- 环境清单脚本修复后尚未在基线机器重新运行；原记录中的图形库清单不可信。
- CMake/Ninja 的安装来源尚未核实，不影响已记录的工具版本，但需补全追溯信息。
- 第三方依赖许可及再分发约束尚未核查（7 个依赖均已确认获取）。
- 当前没有物理场景测试结果或性能数据；4.0.1 仍是候选版本，测试容差和性能目标均未升级为已通过结论。
