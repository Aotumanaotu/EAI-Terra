# M3-04c 执行器面板、动作菜单与预定义动作

> 状态：**已实现并通过基线验证**（2026-11-24 第三次运行全部通过，第 5 节）。依据：[M3-04 设计稿](M3-04-motion-design.md) 第 5、7 节。

## 1. 交付

**查看器：**
- **每步控制器：**打开场景时总是装上，路径为“动作给出的命令（播放中）→ PD 层（有时）→ `setControl`”。查看器、预定义动作测试和自检中的纯物理对照走同一条路径。
- **执行器面板**（菜单 窗口 → 执行器，默认停靠在右侧）：
  - 按模型实例分组，每个执行器一行：名字、类别与单位（PD 层接管的标为“PD 目标”，单位为 rad 或 m）、滑块、输出力；
  - 滑块范围：控制范围；PD 层接管的为关节限位；没有范围时用拖动框；
  - 拖动即修改目标：PD 层接管的交给 PD 层，其余在下一步之前下发。暂停时也能立刻看到新值（面板暂存目标，直到它出现在快照中）；
  - 动作播放时只读，并提示停止动作后才能手动调节；
  - 多输入执行器不支持。
- **“动作”菜单：**
  - **打开动作文件…：**程序内文件浏览，只列 `.terra-motion.json`。当前没有场景时，先打开动作文件中的推荐场景；再按当前场景绑定，PD 层接管的执行器按关节范围校验；
  - **从头播放：**按起始关键帧重置，清除 PD 与面板目标，然后从当前步开始运行；
  - **停止动作；循环。**
  - 动作文件有错误时，在错误弹窗（标题“动作打不开”）中列出全部诊断，当前状态不变。
- **重置：**工具栏、Ctrl+R、按关键帧重置都会停止动作，并清除 PD 与面板目标。
- **状态栏：**动作名、动作时间 / 时长，以及“已结束”或“已停止”。
- **命令行：**新增 `--motion <动作文件>`。没有 `--scene` 时打开推荐场景；自检时在第 3 帧打开，代替按播放。
- **文件浏览：**“只显示…文件”开关的文字改为随后缀变化，场景和动作共用同一个浏览窗口组件。

**预定义动作（`assets/motions/`）：**

| 文件 | 场景 | 内容 |
| --- | --- | --- |
| `g1/wave` | G1 悬挂 | 右臂外展抬起，前臂与手腕来回摆 3 次，放下（约 5.6 s） |
| `g1/squat` | G1 悬挂 | 髋、膝、踝协同下蹲，双臂前伸，保持后站起（5.5 s） |
| `g1/stand_hold` | G1 地面 | 从 stand 开始，保持腿部关节目标 10 s（M3-06 记录能站多久） |
| `go2/lie_stand_sit` | Go2 地面（PD 层） | home → 趴下 → 站起 → 坐下 → 站起（13 s） |
| `stretch3/tour` | Stretch 3 地面 | 两轮同速移动 → 差速转向 → 停 → 升降柱升高 → 伸臂 → 手腕转动、夹爪开合 → 收回（18 s） |

关节角都取在关节限位以内的保守值，没有追求真实步态；是否自然请在展示中确认。

**与设计稿的差异：**
- 动作文件暂不进入“最近打开”列表。这需要设置文件格式升级，留到后续一起做。
- 执行器面板的开关不保存到设置文件。

## 4. 修正与补充（2026-11-24）

**Go2 动作打不开：**`openMotion` 只在**没有场景**时才打开动作文件的推荐场景。展示开始时已经打开了 G1 场景，这时选 Go2 的动作，就会按 G1 场景绑定，找不到 `go2/…` 执行器，弹出“动作打不开”。

测试没有发现这个问题：自检和 `robots.motions` 都是先打开动作对应的场景，没有覆盖“当前场景与动作的场景不同”的情况。

- **修正：**动作文件写了推荐场景、且与当前场景不同时，先切换到推荐场景；没写推荐场景时绑定到当前场景。
- **测试补充：**`graphics.viewer_motion_selftest` 改为先打开两辆小车，第 3 帧打开机械臂动作，必须切换到 `keyframe_arm` 场景。重置后的对照改为重新加载的同一场景的初值。
- **变异补充：**“打开动作时不切换到推荐场景”。

**默认环境改为半球光（不用环境贴图，用户要求）：**
- 设置的默认值由室外贴图改为半球光；设置文件版本 2 → 3。
- 旧文件中的 `"outdoor"` 与旧默认值无法区分，读入时改为半球光，并在日志中提示，用户可在偏好设置中改回；`"studio"` 保持不变；版本 3 文件中的 `"outdoor"` 视为用户的选择，保持不变。
- 四个机器人场景不再在 `view.environment` 中指定摄影棚贴图，跟随用户设置。参考图测试仍固定使用摄影棚贴图，画面不变。
- 查看器自检（非场景模式）在第 0 帧显式切到室外贴图，以继续检查环境贴图管线。
- `settings.store` 增加迁移的三种情况；变异补充“旧设置的室外贴图不迁移”。

**测试总数不变**：57、84。变异测试 4 → **6** 项。
