# M5-02a 场景元素的运行时：实现与验证

> 状态：**基线验证通过**（2026-11-26 第二次运行，第 4 节）。
> 设计见 [M5-01 设计稿](M5-01-scope-design.md) 2.1、2.2 节，2026-11-26 评审通过。

## 0. 为什么分成 M5-02a / M5-02b

Headless（不带图形的构建）也要能打开有元素的场景，结果与查看器相同（M5-03 的完成标准）。而 glTF 的解析在资产模块中，只在开启渲染时构建。所以：

| 部分 | 内容 |
| --- | --- |
| **M5-02a（本步）** | 元素的运行时：<br>- 元素文件；<br>- 场景的 `elements`；<br>- 组合进物理世界；<br>- 显示、温度、分割类别；<br>- 资源库的“元素”卡片。<br>碰撞体都写在元素文件中，运行时不解析 glTF |
| **M5-02b** | glTF 环境的导入：<br>- 按节点拆成元素文件；<br>- 自动生成碰撞代理：按节点包围盒的盒体（`auto-boxes`），或导出节点网格、由 MuJoCo 取凸包（`auto-hulls`）；<br>- 导入向导与命令行。<br>导入的结果就是本步的元素文件，可以人工替换碰撞体 |

**与设计稿的差别：**
- `collision.mode` 在元素文件中写成导入后的结果：`boxes`、`mesh` 或 `none`。`auto-boxes`、`auto-hulls` 作为导入的选项，记在 `generatedBy` 中。
- 按 glTF 节点或材质的温度、节点上的检查点，随 M5-02b 的导入一起做。目前热点与检查点用元素坐标系中的位置。

## 1. 用户能做什么

- **写元素文件**（`*.terra-element.json`），内容包括：
  - 外观：glTF，可指定节点、缩放、位姿；
  - 碰撞体：盒体列表、OBJ / STL 网格（按凸包碰撞），或只显示；
  - 能否移动：`layout`（只在布局编辑中移动）、`fixed`、`dynamic`（自由刚体，按质量与摩擦，机器人可以推动）；
  - 默认温度与热点；
  - 检查点：供 M5-07 使用；
  - 许可：来源、许可证、作者。
- **在场景中引用元素：**`elements` 列表写 `id`、元素文件、位姿，可选实例的温度。同一个元素可以放多份。
- **温度的优先级：**实例写的 `thermal.default` > 场景 `thermal.temperatures` 匹配到的 > 元素文件的默认温度 > 环境温度。
- **分割图：**元素的类别（`category`）自动作为语义类别；场景 `labels` 写了的优先。
- **资源库：**“元素”分页，单击卡片，在只有地面的空场景中预览。卡片显示类别、能否移动、许可；外观文件不在时提示只显示碰撞体。

**内置元素**（`assets/elements/`）：
- 金属工具箱、电钻：可推动；
- 黄铜花瓶：布局可移动；
- 简易配电柜：两个盒体，柜门上有 78 °C 的热点，没有外观模型。

工具箱、电钻、花瓶的外观用 M1-09 已经锁定的 Poly Haven 模型（CC0），碰撞盒按 glTF 的包围盒手写。

**演示场景：**`assets/scenes/robots/go2_elements.terra-scene.json`，Go2 与这 4 个元素，Go2 前方装 Lepton 3.5 热像仪。

## 2. 实现

| 项 | 做法 |
| --- | --- |
| 组合 | 每个元素生成一段 MJCF 文本：<br>- 一个刚体 `body`；<br>- `dynamic` 时带自由关节，质量按盒体体积分配（网格按个数平分）；<br>- 碰撞体为盒体或网格，颜色是半透明的灰。<br>物理后端用 `mj_parseXMLString` 读入，作为实例 `<id>` 排在模型实例之后。实体全名为 `<id>/body` |
| 全局物理设置 | 元素不参与“与第一个实例不同”的比较，随模型实例 |
| 关键帧 | 机器人的关键帧没有给出元素的自由关节，MuJoCo 按初始位置（含放置位姿）补齐，重置时元素不会回到原点 |
| 显示 | 元素的 glTF 作为绑定，挂在 `<id>/body` 上；有外观时碰撞体默认隐藏，可在碰撞体显示中查看 |
| 预览 | 查看器生成只有地面与该元素的场景，放在资源库目录的 `previews/` 下；内存中的库放在系统临时目录。相机按碰撞体的大小取景 |

**变异（6 个）：**
1. 元素的质量不分配；
2. `dynamic` 没有自由关节；
3. 元素的放置位姿丢失；
4. 实例温度不覆盖；
5. 类别不随元素；
6. 元素的全局设置参与比较。

## 4. 基线运行结果

### 4.1 第一次运行（2026-11-26）

| 项 | 结果 |
| --- | --- |
| 渲染关闭 | 114/114 |
| 渲染 Debug | 157/158 |
| Release、ASan、含 ROS2 | 构建失败 |
| 变异 | 6/6 |

**原因：**
- **构建失败：**`SceneModel::mjcfText` 没有默认初始化，旧测试的聚合初始化触发 `-Wmissing-field-initializers`，`-Werror` 下为错误。
- **元素自检“木箱落下”：**要求高度 ≥ 0，落地静止时略低于 0。

**修正：**见 LOG-196。
