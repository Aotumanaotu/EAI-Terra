> 状态：**已实现并通过基线验证**（2026-11-24 第二次运行全部通过，第 3 节）。依据：开发计划 10.2 节 M3-03；M3 评审第 5 条（直接显示 MJCF 网格，补上平滑法线、材质与贴图）。

## 1. 交付

**数据契约（模型描述修订 4）：**只增加字段，原有字段和快照格式不变；Headless 的输出格式也不变。

| 类型 | 新增 | 说明 |
| --- | --- | --- |
| `MeshDescription` | `normals`、`triangleNormals`、`texcoords`、`triangleTexcoords` | 按“三角形角”索引，与 MuJoCo 渲染器的读法相同。法线为 MuJoCo 编译后的值：文件给出的法线，或按面积加权平均，并去掉与平均法线夹角大的面的贡献。纹理坐标沿用 MuJoCo 的约定：v 已翻转，(0, 0) 对应贴图第一行 |
| `TextureDescription` | 名字、类型（二维 / 立方体 / 天空盒）、尺寸、RGBA8 像素 | 只有二维贴图带像素。1–4 通道统一换成 RGBA8 |
| `MaterialDescription` | 颜色、自发光、specular、shininess、reflectance、metallic / roughness（−1 表示模型没有给出）、基础色贴图、重复次数、texuniform | 存 MJCF 原值，换算在显示侧进行 |
| `GeomDescription` | `material` | 材质下标；颜色仍按 M2-03 的规则合成到 `rgba` |

**显示换算（新增 `apps/viewer/mjcf_visual.*`）：**纯 CPU，不调用 OpenGL，可以单独测试。

- **法线：**用 MuJoCo 的平滑法线。某个角的法线与面法线夹角超过 60° 时改用面法线（折角保护）。MuJoCo 只去掉了大夹角面的贡献，个别角的法线仍可能偏得很远，这样处理后棱角保持分明。网格没有法线时按平直着色显示。
- **材质：**

  | 显示参数 | 来源 |
  | --- | --- |
  | 基础色 | 几何体颜色（sRGB → 线性）；有贴图时再乘贴图（按 sRGB 解码） |
  | 粗糙度 | 模型给出的 roughness；没给出时为 1 − 0.9 × shininess |
  | 金属度 | 模型给出的 metallic；没给出时为 0 |
  | 非金属反射率参数 | specular |
  | 自发光 | emission × 基础色 |

  MuJoCo 的默认值（shininess 0.5、specular 0.5）换算后正好是 M2 的显示参数（粗糙度 0.55、反射率 0.5），所以 M2 的场景和参考图 `carts` 不受影响。MuJoCo 的 `reflectance`（平面倒影）不使用，透明度不支持。
- **贴图：**
  - 网格：用自带的纹理坐标，乘以 `texrepeat`。
  - 平面：`texuniform` 时按“每米重复 `texrepeat` 次”；否则按平面尺寸归一化。
  - 其他基本形状：用生成器的纹理坐标，乘以 `texrepeat`。
  - **不支持，只显示颜色：**没有纹理坐标的网格上的二维贴图、立方体贴图。打开场景时给出数量提示。天空盒不使用，天空和环境光仍由查看器的环境设置决定。
- **与 MuJoCo 的差异：**MuJoCo 经典渲染器给基本形状和无纹理坐标网格贴图时，用的是 OpenGL 固定管线的坐标生成，Terra 没有照搬，因此棋盘格的格子大小可能与 MuJoCo 查看器不完全相同。

**场景显示（`SceneView`）：**
- 网格改为平滑着色；二维贴图按下标缓存为 GL 纹理。
- 带贴图的基本形状的网格键加上纹理重复次数，不会与无贴图的同尺寸形状共用网格。

**查看器：**菜单“视图”新增两项，只作用于当前场景，不保存：
- “几何体分组”：分组 0–5 的开关，默认显示 0–2；
- “叠加显示碰撞几何体”。

Menagerie 的约定是可见几何在 group 2、碰撞几何在 group 3。
