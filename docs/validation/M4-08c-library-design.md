# M4-08c 资源库与场景切换：设计稿

> 状态：**评审通过**（2026-11-25，第 4 节 6 个问题按建议）。用户评审时的修正：**重点不是快捷键，而是场景本身就是按钮**——维护好的场景资产
> 都显示为卡片，点一下就加载；`Ctrl+P` 只是辅助。第 2 节“查看器”按此改写（2.1 节）。依据：
> - [M4-08 设计稿](M4-08-import-design.md)第 4 节（资源库面板）、8.3 节（资源库位置可设置、资产包的导出与导入）；
> - 用户在 M4-08b 验收时的意见：“切换场景变得不好用；已经引入数据库了，导入的机器人场景没有索引到数据库。”

## 1. 现状与问题

- 资源库（SQLite，M3-07b）目前只登记**实验记录**。
- 场景、机器人、动作、环境贴图、导入的模型都没有登记。
- 切换场景只能用：
  - “文件 → 打开场景…”：逐级找文件，导入的 TurtleBot 4 在 `assets/robots/turtlebot4/` 下，用户导入的在资源库目录下，都要翻几层；
  - “最近打开”：只有用过的。
- 导入成功后只打开一次，之后要自己去找。

## 2. 方案

**资源库登记全部资产**（数据库新增资产表，原有的记录表不变）：

| 字段 | 含义 |
| --- | --- |
| 类型 | 场景、机器人（导入目录或参考机器人）、动作、环境贴图、显示配置（M4-08d） |
| 名字、路径 | 路径唯一 |
| 来源 | 内置（仓库自带，只读）、导入、用户 |
| 关联 | 场景 → 用到的机器人；动作 → 推荐场景；导入 → 配方与报告 |
| 其他 | sha256、许可、创建与修改时间、缩略图（可选） |

**何时登记：**
- 导入成功时（向导与命令行 `terra_import`）自动登记机器人与它的场景；
- 启动时增量扫描内置目录（`assets/scenes/`、`assets/robots/*/`（含导入生成的 TurtleBot 4）、`assets/motions/`、`assets/hdri/`）与资源库目录下的 `assets/`：只处理修改时间变化的文件，几十毫秒内完成；
- 被删除的文件在下次扫描时标为“缺失”，不自动删除登记。

**查看器：**见 2.1 节。

**资源库位置：**偏好设置中新增“资源库位置”（M4-08 设计稿 8.3 节）。修改后提示重新打开资源库；原位置的数据不自动搬移，提供“复制到新位置”按钮。

**资产包**（M4-08 设计稿 8.3 节）：
- 命令行：`terra_import --export-pack <导入目录> <文件.terra-pack>`、`terra_import --import-pack <文件.terra-pack> [--output-root 目录]`；查看器中在导入的卡片上右键“导出资产包”。
- 解包时拒绝绝对路径与含 `..` 的条目，逐个核对 manifest 中的 sha256。
- 导出：把一个导入目录（模型、网格、贴图、场景、配方、报告与源模型的 LICENSE）打包成一个 `.terra-pack` 文件。格式为 zip，内含 `manifest.json`。
- 导入：解包到资源库目录并登记，不需要重新转换。

**Headless：**新增 `--list-assets [--kind 类型]`，与 `--list-records` 相同的每行一个 JSON。

### 2.1 查看器：一键打开的场景卡片（用户评审时的修正）

**原则：**场景、动作是维护好的资产，用户不需要知道文件在哪里。打开查看器就能看到全部场景，**单击卡片即加载**，不需要确认、不弹文件窗口。

| 位置 | 内容 |
| --- | --- |
| **资源库面板**（新，停靠在左侧，大纲之上；左侧栏由 17% 加宽到 20%） | 顶部：搜索框、网格 / 列表切换；分页：**场景**（默认）、动作、机器人；筛选：全部、收藏、最近、内置、导入。下面是卡片 |
| **欢迎页**（没有打开场景时，视口中央） | 大号卡片网格，收藏与最近使用的在前；一眼就能挑一个开始 |
| “文件 → 资源库中的场景” | 子菜单按来源分组，点一下打开 |
| `Ctrl+P` | 辅助：搜索框，输入名字的一部分，方向键选择，回车打开（场景与动作） |

**卡片：**
- 矢量图标（按类型着色，与文件浏览窗口一致）、短标题、一行说明（场景文件的 `name`）；
- 小标签：来源（内置 / 导入）、传感器（IMU、相机、雷达）、预定义动作的数量；
- 右上角的星标：单击收藏 / 取消，不会打开场景；
- 当前打开的场景用强调色描边并标“当前”；
- 悬停时显示完整说明与路径；
- 文件缺失的条目不显示（面板底部给出数量）。

**单击的效果：**
- 场景：立即打开（与“打开场景”相同，失败时弹出诊断）；
- 动作：打开推荐场景并从头播放；
- 机器人：打开用到它的第一个场景，右键菜单列出全部场景。

**右键菜单：**收藏、复制路径、在文件管理器中显示、按配方重新导入（导入的条目）、导出资产包（导入的条目）、隐藏（不删文件；面板底部可恢复）。

**短标题：**场景文件新增可选字段 `title`（如 “宇树 G1 悬挂”），卡片显示它，没有时显示 `name`。仓库中的 9 个场景补上 `title`；导入生成的场景写入 `title`（配方的新字段 `title`，没有时为实例名）。

**“最近”**沿用设置中的最近打开列表（已有，不需要写库）；**收藏**写入资源库。

**不在用户目录中建库：**资源库文件还不存在时，卡片列表来自内存中的临时库（启动时扫描，几毫秒）；第一次收藏、保存记录或导入时才建立资源库文件。自检（`--self-test`）没有给出 `--library` 时只用内存中的库，不读写用户目录。

## 4. 需要评审的问题

| # | 问题 | 建议 | 其他选项 |
| --- | --- | --- | --- |
| 1 | 扫描范围 | 内置目录与资源库目录在启动时增量扫描；测试夹具（`assets/tests/`）不登记 | 只登记用户导入的 |
| 2 | 快速切换 | `Ctrl+P` 搜索框（场景与动作），可在偏好设置中改 | 只做资源库面板 |
| 3 | 资产包格式 | zip（`.terra-pack`），用 miniz（单文件 C 库，MIT 许可）读写，按 sha256 锁定 | 不压缩的目录加 manifest（不需要新依赖，但不是一个文件，不方便发送） |
| 4 | 缩略图 | 本步不做：以后用离屏渲染生成（M4-03a 已有离屏渲染），先显示矢量图标 | 本步就做 |
| 5 | 资源库位置的修改 | 修改后重新打开资源库，提供“复制到新位置”，不自动搬移 | 自动搬移 |
| 6 | 与 M4-08d（ROS2 面板）的顺序 | 先做本步（资源库是显示配置的存放处），再做 M4-08d | 先做 M4-08d |
