# M3-04a 动作文件与播放

> 状态：**已实现并通过基线验证**（2026-11-24，第 4 节）。依据：[M3-04 设计稿](M3-04-motion-design.md) 第 2 节，2026-11-24 评审通过，6 个问题均按建议。

## 1. 交付（`terra_simulation`）

| 接口 | 说明 |
| --- | --- |
| `parseMotion` / `readMotionFile` | 读取并校验动作文件（`*.terra-motion.json`），得到 `MotionDocument`。推荐场景的路径相对动作文件所在目录 |
| `bindMotion` | 把动作绑定到一个世界的模型描述上，得到 `BoundMotion`（按执行器分开的轨道） |
| `sampleTrack` | 轨道在动作时间 t 的值。三种插值：`step`、`linear`、`smooth`（smoothstep，在点上速度为 0） |
| `MotionPlayer` | 开始步、动作时间、结束、循环；`commands(step, 步长)` 给出某一步之前要下发的命令 |
| `SimulationRunner::setController` | 每步控制器：每一步之前、在排队的命令之后调用，返回的命令交给 `setControl`，被拒绝的命令进入 `FrameResult::controlErrors` |

`nlohmann/json` 只在 `motion_file.cpp` 中使用。`boundary.render_isolation` 的 JSON 允许目录增加了 `engine/simulation/src/`。

## 2. 规则

**文件校验**，与场景文件的约定相同：
- 未知字段一律报错；`format`、`version` 必须正确；
- `poses` 不能为空，时间不能为负且必须严格递增，`targets` 必须是非空对象，目标值必须是有限数值；
- 一次报出全部问题。

诊断位置用 JSON 指针。执行器名中的 “/” 按 RFC 6901 写作 “~1”，例如 `/poses/0/targets/g1~1left_knee`。

**绑定时校验**，同样一次报出全部问题：
- **执行器不存在：**带了前缀的，列出该实例的执行器（最多 8 个）；没带前缀的，提示写法；前缀本身不存在的，说明没有这个实例。
- **多输入执行器：**不支持。
- **越界：**目标超出控制范围时拒绝（评审问题 3）。范围函数可以替换，M3-04b 的 PD 层会改用关节限位。
- **起始关键帧不存在：**列出场景中的关键帧。
- **Other 类执行器：**每个只警告一次，目标值照常下发。

**播放：**
- **时间：**动作时间为 (步 − 开始步) × 步长，与墙钟、帧率、暂停、单步都无关。
- **第一个点之前：**某个执行器在第一个提到它的点之前不下发，保持当前控制量。
- **最后一个点之后：**保持最后的值。
- **循环：**动作时间对时长取模。

## 3. 测试

**夹具（`assets/tests/motion/`）：**
- `arm_swing.terra-motion.json`：驱动 `keyframe_arm` 场景的位置、速度、力矩三类执行器，有起始关键帧，三个执行器出现的时间点各不相同。
- `invalid.terra-motion.json`：含 5 个错误。

| 测试 | 内容 |
| --- | --- |
| `motion.file`（新增，纯逻辑） | **文件：**夹具的全部字段、路径展开与默认值；推荐场景不存在时只给警告。**错误：**16 个错误用例的 JSON 指针与原因，一次报出 5 个错误，文件不存在。**插值：**三种插值的数值，第一个点之前不下发，最后一个点之后保持，smooth 在点上的斜率为 0。**播放器：**开始步、动作时间、结束、循环、停止。另带 `--diagnose` 演示模式 |
| `motion.player`（新增，MuJoCo） | **绑定：**夹具通过；未知执行器、没带前缀、越界、未知起始关键帧都报错；Other 类执行器只警告；一次报出 3 个错误。**播放：**60 Hz、144 Hz、随机抖动的帧间隔得到逐位相同的轨迹；单步与连续推进逐位相同；与“每步预先排队同样的命令”逐位相同；结束后肩关节保持在最后的目标附近；控制器给出的无效命令被报告；重播逐位相同 |

**测试总数：**渲染关闭 52 → **54**，渲染开启 78 → **80**。

**变异测试 8 项**（`scripts/verify/m3_04a.sh`，支持 `--mutation-only`）：
- 文件：时间不检查递增；JSON 指针不转义。
- 插值：smooth 退化为线性；第一个点之前也下发；结束后不保持。
- 绑定：越界不拒绝。
- 播放：动作时间不减开始步；runner 忽略控制器。

本步没有新界面，不打开窗口。
