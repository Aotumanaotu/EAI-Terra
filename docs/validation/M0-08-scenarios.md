## 1. 范围与做法

开发计划 M0-08 的 7 个步骤：①运行立方体主夹具 ②对照碰撞前解析自由落体 ③检查接触与末段稳定 ④无重力夹具检查惯性状态 ⑤单铰链夹具检查关节读取与控制方向 ⑥记录模型、配置、输出与失败诊断 ⑦评审并冻结候选容差。

做法：

- 所有门槛集中在 `tests/physics/m0_tolerances.hpp`，各测试只从这里取值，**唯一数值来源**；本报告第 4 节逐项给出理由。
- 新测试每项判定都打印 `METRIC <夹具> <判定> 实测 <值> 门槛 <值> PASS|FAIL`，失败时另打印带**夹具、步数、状态字段**的 `FAILED:` 行，开头打印后端版本（步骤 ⑥，计划验收标准“每个失败能关联到夹具、步数、版本及状态字段”）。
- M0-05/06 已有的主基准检查保留为回归；M0-08 的 `physics.scenarios` 在一次 5000 步运行中给出全部 4.2 节判定，作为正式判定。

## 2. 核查发现

1. **“模型重载后旧 ID 明确失效”在原契约下做不到。**实体/关节/执行器 ID 只是数值，重新加载同一模型得到的 ID 数值完全相同，消费者无法区分新旧世界。
   → 新增**世界实例号** `worldInstance`（`ModelDescription` 与 `PhysicsSnapshot`）：每次成功加载分配一个进程内唯一、递增的值，失败的加载不消耗编号。消费者比较实例号即可判定 ID 或快照是否属于当前世界。快照字段只增不改，Headless 输出不变，`contract_revision` 保持 1。
2. **MuJoCo 的致命错误不可接管。**4.0.1 的 `mju_error` 默认处理（`engine_util_errmem.c`）是打印到 stderr 后 `exit(EXIT_FAILURE)`。Terra 公共接口的合法调用经校验后不会触发它；无法从进程内恢复，因此按技术设计 2.2 节在子进程中固定行为（`physics.backend_fatal`）：退出码 1（与 Headless 内部错误码相同）、stderr 带 MuJoCo 原文、atexit 仍执行、不写 `MUJOCO_LOG.TXT`。**M2-02 更新（2026-11-23）：**Terra 改为登记自己的日志处理函数，退出码改为 70，退出前写崩溃报告并执行紧急保存，见 [M2-02/03 报告](M2-02-03-fatal-geometry.md)。
3. **加载期的运行内存不足不会终止进程。**原计划用 `<size memory="16"/>` 触发致命错误，但核查编译器源码（`user_model.cc` 中 `compilerLogHandler` 与编译期试跑 `mj_step`）发现：编译时的栈溢出被编译器捕获并转成编译错误。因此该夹具改为验证“加载期内存不足 → 模型错误，退出码 4，消息含 `mj_stackAlloc`”（`headless.arena_too_small`）。运行期才出现的内存不足，触发条件依赖接触规模，没有可靠的固定夹具，M0 不覆盖。
4. **“初始化前 step”在类型层面不可能发生**（M0-07：加载失败不产生世界对象），无需运行期用例。

## 3. 覆盖对照（开发计划 4.2 / 4.3 节）

### 3.1 主场景（4.2 节）——`physics.scenarios` 一次 5000 步运行

| 检查 | 判定 | 门槛来源 |
| --- | --- | --- |
| 时间 | 每步 \|t − k·dt\| 的最大值；严格单调 | `kTimeError` |
| 自由落体 | t ∈ [0.05, 0.20] s 与 z = 1 − g·t²/2 的最大误差（记录最差步）；碰撞前每步 v_z < 0 且 z 递减；全程 x/y 漂移 | `kFreeFallError`、`kPlanarDrift` |
| 发生接触 | 首次有效接触时刻（并打印步数） | `kFirstContactBegin/End` |
| 最终稳定 | 最后 0.5 s：高度误差、线/角速度、每步存在 (world, cube) 有效接触、法向力 ≈ m·g | `kRestHeightError` 等 |
| 数据有效 | 每步 `diagnostics.finite`；四元数范数误差；**最终姿态与单位姿态的旋转角（按 q/−q 等价）** | `kQuaternionNormError`、`kFinalOrientationAngle` |
| 观测一致 | 持有的第 100 步快照在之后 4900 步中不变 | — |

## 4. 冻结的容差（`tests/physics/m0_tolerances.hpp`，2026-11-18 冻结）

适用条件：MuJoCo 4.0.1，当前 `falling_cube.xml`、`floating_cube.xml`、`hinge_motor.xml` 参数，dt = 0.001 s，Euler。换版本、积分器或夹具参数必须重新评审。

“基线实测”为 2026-11-18 基线机器 Release 构建的 `physics.scenarios`/`physics.continuous` 输出，与 M0-05/06 在开发机和基线机器上的实测在打印精度内一致。

| 判定 | 门槛 | 基线实测 | 理由 |
| --- | --- | --- | --- |
| 时间误差 | ≤ 1e-8 s | 3.30e-13 s（5000 步）；4.91e-11 s（60000 步） | 浮点累加误差远小于门槛；超过即说明步长或时间推进有误 |
| 自由落体误差（0.05–0.20 s） | ≤ 0.005 m | 9.81e-4 m（与理论偏差一致） | 半隐式 Euler 理论偏差 g·dt·t/2，在 0.2 s 为 9.81e-4 m；留 5 倍余量，坐标或重力方向错误会远超门槛 |
| 平面漂移 | ≤ 1e-9 m | 1.54e-15 m | 无水平力，只容纳舍入误差。**比计划“无显著漂移”收紧** |
| 首次有效接触 | 0.35–0.55 s | 0.428 s（第 428 步） | 理想触地 ≈ 0.428 s；窗口容纳软接触与离散步长 |
| 稳定高度误差 | ≤ 0.005 m | 1.08e-4 m | 含软接触允许的穿透；不靠收紧逼近刚性零穿透 |
| 稳定线速度 | ≤ 0.01 m/s | 3.98e-14 m/s | 计划值；实测远低于门槛 |
| 稳定角速度 | ≤ 0.05 rad/s | 3.76e-13 rad/s | 计划值 |
| 静止法向力 | 与 m·g 相对偏差 ≤ 1% | 2.88e-11 | 静力平衡 |
| 四元数范数误差 | ≤ 1e-6 | 0 | 计划值 |
| 最终姿态旋转角 | ≤ 0.01 rad | 0 | **新增**：平落无转矩，理想为 0；按 q/−q 等价比较 |
| 无重力位姿/速度变化 | ≤ 1e-12 | 位姿 0，速度 0 | **新增**：没有任何力，只容纳舍入误差 |
| reset 再运行轨迹差 | ≤ 1e-9 | 立方体 0，铰链 0（20 周期，逐位相同） | 计划候选值；同环境下预期逐位相同，门槛不代表跨平台承诺 |
| 连续运行 | 60000 步无错误、全程有限、最终高度误差 ≤ 0.005 m | 60000 步完成；四元数误差 0；最终高度误差 1.08e-4 m | 计划值 |

**评审要点：**除“平面漂移”收紧、“最终姿态旋转角”和“无重力”两项新增外，其余沿用计划候选值。理由是：这些值有物理依据，实测值都远在门槛以内，而按实测值收紧只会让测试对无害的数值变化变得脆弱。基线结果中新增三项的实测值均为 0，与预期一致，按本表冻结。之后修改任何门槛都要同时更新本表的理由，并重新在基线机器上验证。
