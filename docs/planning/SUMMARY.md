## 3. 验证结论与适用范围

既有[M0-01 验证记录](../validation/M0-01-environment.md)记载：在 Ubuntu 22.04.5 / x86-64 基线机器上，使用 GCC 11.4.0、CMake/CTest 3.22.1、Ninja 1.10.1，Debug 与 Release 干净构建均成功，CTest 均为 **6/6 通过**；Release 启用了 `-Werror`。

这些结果来自既有记录，本轮没有重新执行编译或 CTest。它们只能证明当前工程骨架的记录结果，不能证明 MuJoCo 集成、无图形物理仿真、接触精度、传感器或性能达标。

仍需保留的验证限制：

- 环境清单脚本修复后尚未在基线机器重新运行；原记录中的图形库清单不可信。
- CMake/Ninja 的安装来源尚未核实，不影响已记录的工具版本，但需补全追溯信息。
- MuJoCo 候选来源、校验值、头文件/运行库兼容性、获取脚本的实际执行结果均未在本轮验证。
- 当前没有物理测试结果或性能数据；候选测试容差和性能目标均未升级为已通过结论。
