# M4-02 IMU

> 状态：**已实现并通过基线验证**（2026-11-24 第一次运行全部通过，第 5.2 节）。依据：[M4-01 传感器设计稿](M4-01-sensor-design.md)（2026-11-24 评审通过）。

## 1. 交付

**数据契约：**
- `SensorId`；模型描述修订 6：`SensorDescription`（名字、类别、安装的实体与实例、安装位姿、是否由场景添加）与 `ModelDescription::sensors`。
- 快照修订 3：`PhysicsSnapshot::sensors`。IMU 的读数为 10 个数：比力 3 个（m/s²）、角速度 3 个（rad/s），都在安装点坐标系中；安装点在世界中的姿态 4 个（wxyz）。
- Headless 的默认输出不变（`kOutputRevision` 仍为 1）。

**与设计稿的一处细化：**设计稿写的是“快照只含本步采样了的读数”。实现时改为**快照总是给出全部物理侧传感器的当前读数**，按频率采样由使用方决定（`terra::simulation::sensorSampleDue`）。原因：
- 快照与使用方无关；Headless、记录、ROS2 桥接可以各自按需要的频率取；
- IMU 读数是 MuJoCo 每步都会算的，取出来几乎没有开销。

激光雷达的射线检测开销较大，在 M4-03b 中由使用方只在采样步上调用。

**MuJoCo 后端：**
- **发现：**同一安装点（site）上同时有加速度计与陀螺仪即为一个 IMU（各取第一个），名字为安装点全名，按安装点顺序编号。只有其中一种的安装点不算。
- **读数：**比力与角速度直接取 MuJoCo 传感器的输出；姿态由安装点的世界旋转矩阵换算。MuJoCo 计算加速度计时会自动做约束后的递推（`mj_rnePostConstraint`），比力包含接触与约束的效果。
- **场景添加：**组合时在实例自己的模型中（加前缀之前）插入：
  - 装在实体上：新建安装点；
  - 装在已有安装点上：只补上缺少的加速度计或陀螺仪，已经齐全时不做任何改动。
  插入的传感器名字带隐藏标记，不对外显示，也不与模型中的名字冲突。
- **噪声：**已核对 MuJoCo 4.0.1 的引擎源码，`sensor_noise` 没有被使用。因此 MJCF 中的 `noise`（G1 的 IMU 写了）不会施加，读数是无噪声的真值。`cutoff` 按 MuJoCo 的规则截断。

**场景文件 `sensors`：**
```json
"sensors": [
  {"type": "imu", "site": "go2/imu", "rateHz": 500},
  {"type": "imu", "name": "g1/head_imu", "entity": "g1/torso_link", "position": [0.05, 0, 0.4], "rotation": {"rpyDeg": [0, 0, 0]}}
]
```
- `site` 与 `entity` 二选一。装在已有安装点上时，名字就是安装点名，不能再写位姿。装在实体上时 `name` 必填，并带同一实例的前缀。
- `rateHz` 省略时等于物理频率；高于物理频率时按物理频率采样，并给出警告。
- `camera` 与 `lidar2d` 在 M4-03 加入，现在写了会报“当前版本还不支持”。
- 错误按场景文件的一贯做法给出 JSON 指针与原因；找不到安装点或实体时，列出模型中已有的。
- `SceneInstance::sensors`：每个传感器实际采用的频率。

**采样时刻（`terra/simulation/sensor_sampling.hpp`，设计稿问题 1）：**
- 第 k 步满足 ⌊k·Δt·f⌋ > ⌊(k−1)·Δt·f⌋ 时采样，第 0 步总是采样；
- 500 Hz 物理、30 Hz 时间隔在 16 与 17 步之间交替，平均正好 30 Hz，长时间不漂移；
- 频率不低于物理频率时每步采样（含 (1/Δt)·Δt 的舍入）。

**Headless `--sensors`：**
- `model` 之后输出一行 `sensor_list`（清单与频率）；
- 之后按各传感器的频率输出 `sensor` 行（`linear_acceleration`、`angular_velocity`、`orientation`），第 0 步总是输出；
- 不能与 `--rerun`、`--list-records` 同用；不加 `--sensors` 时输出与以前完全相同。

**测试总数：**渲染关闭 73 → **78**，渲染开启 102 → **107**。

**变异（9 个）：**
- 加速度与角速度对调；
- 场景添加的标记丢失；
- 已有安装点缺的传感器不补；
- 装在实体上的安装角丢失；
- 频率不限制在物理频率以内；
- 场景写的频率不生效；
- 采样时刻每步都采；
- Headless 只在第 0 步输出读数；
- Headless 不用场景的频率。

**没有窗口展示：**本步只有数值。传感器面板（IMU 曲线）在 M4-04；验证脚本第 6 步打印夹具与 G1 的读数。

## 4. 已知的限制

- 没有名字的安装点上的 IMU 名字为空（参考机器人的 IMU 安装点都有名字）。
- MJCF 中给传感器设置了延迟（`delay` / `nsample`）时，读数是 MuJoCo 延迟后的值。参考机器人都没有设置。
