# M1-08 网格、材质与光照（设计稿）

> 状态：**设计待评审**，未实现。关联 D-004、D-021、D-027（自研 PBR，参考 Filament 的公开文档）、F-M1-02、F-M1-03。
> 开发计划原写“基础材质与方向光（Blinn-Phong）”，D-027 定为自研 PBR 后改为下述方案（评审通过后同步修改开发计划 M1-08 行）。

## 1. 目标观感

视口从“顶点色的预览场景”升级为接近 Blender Eevee / UE5 默认场景的观感：金属与粗糙度材质、太阳光与柔和环境光、实时阴影、色调映射与抗锯齿；地面网格与坐标轴保持编辑器风格。参数与 glTF 2.0 的金属度-粗糙度材质一致，为 M1-09 加载 glTF 资产与后续 MuJoCo 模型显示做准备。

## 2. 分两步交付

| 步骤 | 内容 | 需要的素材 |
| --- | --- | --- |
| **M1-08a 直接光照 PBR** | 程序生成网格（含法线）；PBR 材质；太阳光 + 半球环境光；方向光阴影；HDR 离屏渲染、曝光、色调映射、sRGB 输出；4× MSAA；着色器网格线 | 无 |
| **M1-08b 基于图像的光照（IBL）** | 读取 HDR 环境贴图；预计算漫反射辐照度、按粗糙度预过滤的镜面反射图与 BRDF 查找表；环境贴图可作为背景显示 | **需要你下载 HDRI**（见第 8 节） |

先做 a：不依赖素材、可以完全自动化验证；b 在 a 通过后进行，届时 HDRI 应已就位。

## 3. 渲染模块扩展（`terra_render`，公共接口仍只用 Terra 类型）

| 新增 | 说明 |
| --- | --- |
| `Texture2D`、`TextureCube` | RAII；格式 RGBA8 / RGBA8_SRGB / RGBA16F / RG16F / DEPTH32F；mipmap；采样参数 |
| `Framebuffer` 扩展 | 多种颜色格式、可选多重采样（MSAA）、仅深度（阴影图）、`resolveTo` |
| `Buffer` 用途扩展 | 索引缓冲、uniform 缓冲（std140，按帧更新的相机与光照数据） |
| `RenderContext` | `drawIndexed`、混合 / 面剔除 / 深度写入开关 |
| `Mesh` 与网格生成 | 顶点：位置、法线、切线、UV；索引三角形。生成器：平面、立方体、UV 球、圆柱、胶囊、圆锥（覆盖 MuJoCo 的几何体类型，M2 复用） |
| `Material` | `baseColor`（线性 RGBA）、`metallic`、`roughness`、`emissive`、`reflectance`（非金属 F0，默认 0.5 → 4%）；M1-09 起可带贴图 |
| `Light` | 太阳光：方向（方位角 / 高度角）、颜色、照度；半球环境光：天空色 / 地面色 / 强度（a 阶段的环境光，b 阶段由 IBL 取代） |
| `SceneRenderer` | 每帧：阴影图 → 不透明物体（HDR、MSAA）→ 网格线与坐标轴 → 解析 → 色调映射 + sRGB → 视口纹理（交给 ImGui 显示） |

## 4. 着色模型（参考 Filament 文档的标准模型）

- 镜面：Cook-Torrance，GGX 法线分布，高度相关 Smith-GGX 可见性项，Schlick 菲涅耳；`α = roughness²`，粗糙度下限 0.045 防止高光闪烁。
- 漫反射：Lambert；金属度插值：`diffuse = baseColor·(1−metallic)`，`F0 = mix(0.16·reflectance², baseColor, metallic)`。
- 光照单位：太阳照度为相对值（默认 3.0），由单一曝光参数控制亮度；不引入物理相机（EV100）——留待 M3 画质评估时决定。
- 环境光（a 阶段）：半球光（按法线 Z 在天空色与地面色之间插值）× 漫反射，镜面部分用粗糙度近似；b 阶段替换为 IBL。

## 5. 颜色管线、抗锯齿与阴影

- **线性工作流**：材质颜色以线性值存储；着色在 RGBA16F 中进行；最后一步色调映射并编码为 sRGB 写入 RGBA8 视口纹理（ImGui 直接显示）。界面主题颜色不受影响。
- **色调映射（建议默认 AgX，可在设置中切换）**：AgX（Blender 4 默认，高光过渡自然）、Khronos PBR Neutral（基础色还原最准确，适合检查材质）、ACES（近似 UE 的电影感）、无（线性截断，仅调试）。曝光默认 0 EV，可调。
- **抗锯齿**：4× MSAA（可在设置中改为关 / 2× / 8×）。
- **阴影**：太阳光单张阴影图（2048²），按场景包围盒拟合正交投影；3×3 PCF 软化；坡度偏移防止“阴影痤疮”。级联阴影（大场景）留到 M2/M3。
- **网格线**：改为着色器绘制的无限地面网格（1 m / 10 m 两级，随距离淡出，X 轴红线、Y 轴绿线），与 Blender 视口相同的观感；Z 轴保留为短线段。

## 6. 视口演示场景

替换现有预览：地面平面（浅灰、粗糙）；“材质球”阵列——5×2 个球体，一行金属度 0→1、一行粗糙度 0→1；一个立方体、一个圆柱、一个胶囊；太阳光投下阴影。属性面板（Details）新增“渲染”分组：太阳方位角 / 高度角、强度、环境光强度、曝光、色调映射、MSAA、阴影开关——修改立即生效并写入设置文件（`render` 组，沿用 M1-14 机制）。

## 7. 测试计划

| 测试 | 内容 |
| --- | --- |
| `render.brdf`（不需要 GPU） | 着色公式的 C++ 参考实现与 GLSL 共用同一份常数：GGX/Smith/Schlick 的已知数值、能量上界（白色漫反射在正对光源时不超过照度/π）、金属度插值；三种色调映射在 0、中灰、高光处的数值与单调性 |
| `render.mesh`（不需要 GPU） | 网格生成：顶点/索引数、法线单位长度且朝外、绕序一致、包围盒、UV 范围、胶囊与圆柱的尺寸约定（与 MuJoCo 一致：半长 + 半径） |
| `graphics.render_pbr`（Xvfb + llvmpipe） | 固定相机下渲染单个球体：正对光源处的像素与 C++ 参考值（经同一色调映射）相差 ≤ 2/255；背光处只有环境光；金属球比非金属球在同一位置更暗的漫反射；阴影：地面阴影区域明显暗于受光区域；MSAA 开启后边缘像素出现中间值；全程无 GL 错误 |
| `graphics.viewer_selftest`（更新） | 视口中心像素改为与光照后的期望值比较；渲染参数修改立即生效并可保存读回 |
| 变异测试 | 例如：菲涅耳指数写错、可见性项缺失、色调映射前未乘曝光、法线未归一化、阴影比较方向反了 |
| 性能 | 记录 RTX 5060 在 4K 视口下的帧耗时（为 M1-10 基线做准备），目标：演示场景 ≥ 60 FPS |

像素级比较只在 llvmpipe 上进行（D-022）；真实 GPU 上运行同一自检，容差放宽并只做结构性检查。

## 8. 需要你准备的素材（M1-08b，现在就可以开始找）

**HDRI 环境贴图**，推荐来源 **Poly Haven**（<https://polyhaven.com/hdris>）：全部为 **CC0**（可商用、可再分发、无需署名），质量高，是 Blender 社区的常用来源。

请下载 **2 张**，格式 **`.hdr`，分辨率 2K**（2048×1024，约 6 MB；4K 也可以，但测试和仓库体积更大）：

| 用途 | 建议 | 说明 |
| --- | --- | --- |
| 默认环境（室外、柔和） | 例如 `kloofendal_48d_partly_cloudy_puresky`、`rural_asphalt_road` 或同类“少云天空”贴图 | 机器人仿真常用的室外光照 |
| 摄影棚（中性、均匀） | 例如 `studio_small_09`、`studio_small_08` 或同类 studio 贴图 | 检查材质颜色、做画质基线 |

下载后放到任意目录告诉我路径即可；我会记录文件名、来源页面、sha256 与许可，并决定是提交进仓库（`assets/hdri/`）还是像 MuJoCo 一样用脚本按 sha256 获取。读取 `.hdr` 计划使用 **stb_image**（单头文件，公有领域/MIT 双许可，源码锁定）。

M1-08a 不需要任何素材。
