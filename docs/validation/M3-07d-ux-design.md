# M3-07d 记录、回放与执行器面板的交互改进：设计稿

> 状态：**评审通过**（2026-11-24），**已实现并通过基线机器验证**（2026-11-24，第 5.3 节）。依据：用户对 M3-07c 的意见（见 [M3-07c 报告](M3-07c-viewer-record.md) 第 3 节）。
>
> 评审结论：
> 1. 录制快捷键用 `Ctrl+Shift+R`；
> 2. 播放控制在视口工具栏与时间轴标签页中都放，时间轴要设计得专业一些；
> 3. “实测”按执行器类型区分；
> 4. “实验记录”窗口合并进时间轴标签页。

## 1. 参考

| 软件 | 可借鉴之处 |
| --- | --- |
| Blender 时间轴 | 底部停靠的“时间轴”编辑器：一行播放控制（跳到开头、播放 / 暂停、单步）、当前时间、自动记录的红色圆点按钮；下面是可拖动的时间刻度 |
| Unreal Sequencer / Take Recorder | 录制按钮常驻在工具条上，录制时变成红色并显示录制时长；录下的内容（Take）列在旁边，双击即可回放 |
| NVIDIA Isaac Sim | 视口上方是播放、暂停、停止；底部停靠时间轴，仿真时间与回放共用同一条刻度 |
| OBS Studio | 录制按钮显示“正在录制”与时长，并且可以设置快捷键 |

**共同点：**
- 播放与录制控制放在显眼、固定的位置，一键即可；
- 时间轴停靠在底部，与日志等面板并列；
- 录下的内容就在时间轴旁边，不需要另开窗口去找。

## 2. 方案

### 2.1 视口工具栏：加一个录制按钮

```
 ▶ 播放   ⏭ 单步   ⟲ 重置   1×▾  │  ● 录制            运行中  12.344 s
                                     （录制中：■ 00:07.3  2.1 MB，红色）
```

- 录制按钮常驻在工具栏上。点一下开始，再点一下停止；录制时变成红色，显示录制时长与文件大小。
- 快捷键：在偏好设置的“按键”页新增“仿真：开始 / 停止记录”，可以修改。默认键见评审问题 1。
- 菜单“仿真”中的同名项保留，作为第二个入口。

### 2.2 底部新增“时间轴”标签页，与“日志”“统计”并列

```
┌ 日志 │ 统计 │ 时间轴 ─────────────────────────────────────────────────────────┐
│ ● 录制   ▶ 播放   ⏮ ⏭   1×▾      [ 实时 | 回放 ]        00:07.30 / 00:14.08        │
│ ├────────┬────────┬────────┬────────┬────────┬────────┬───────▲─┬────────┤        │
│ 0s       2s       4s       6s       8s      10s      12s       14s               │
│ ───────────────────────────────────────────────────────────────────────────── │
│ 本场景的记录                                                    重新扫描  全部场景 │
│  ▸ 06:02:49  go2 · 趴下站起坐下     22.2 s   1110 份   8.4 MB   完成    ▶ 回放   │
│  ▸ 06:00:48  g1 悬挂 · 挥手         14.1 s    705 份   4.1 MB   完成    ▶ 回放   │
└─────────────────────────────────────────────────────────────────────────────────┘
```

- **实时模式：**刻度显示仿真时间，录制时用红色标出已录制的区段。
- **回放模式：**刻度就是记录的时长，可以拖动播放头；事件（重置、错误）在刻度上标成小三角。点“实时”即退出回放。
- **记录列表：**默认只列当前场景的记录，可切到全部场景；双击或点“回放”即可回放（需要时自动切换场景）。原来的“实验记录”窗口合并到这里，菜单项改为打开这个标签页。
- **布局：**首次打开、或“恢复默认布局”时，“时间轴”与“日志”“统计”停靠在同一组；已保存的布局中没有这个标签时，首次显示自动并入这一组。

### 2.3 执行器面板：一行一个“实测 + 目标”控件，回放时同步

```
g1 ─────────────────────────────────────────────────────────────
 left_elbow_joint            位置 · rad          1.21  →  1.28
 ███████████████████████████████▍···········│·····················
                                                  ↑ 目标（可拖动）
 right_shoulder_roll_joint   位置 · rad         -1.47  → -1.50
 ████████████▏··│·················································
```

- **一个控件同时表示两件事：**
  - **填充条**表示实测量：位置执行器与 PD 层是关节位置，速度执行器是关节速度，力矩执行器是输出力或力矩；
  - **竖线**表示目标（控制量）。
- **跟随：**物理一推进，填充条就跟着动，满足“输出在动时，滑块也跟着动”。拖动控件即修改目标，竖线跳到新位置，填充条随物理跟过去。
- **数字：**右侧显示“实测 → 目标”，等宽数字。实测超出范围时，填充条变为红色；鼠标悬停时显示实际输出力与传动比等细节。
- **只读状态：**动作播放与回放时只读，竖线变灰。回放时实测取记录中的关节状态，目标取记录中该时刻的控制量，与时间轴同步。
- **分组：**按模型实例折叠分组。执行器多时（G1 有 29 个）提供按名字过滤的输入框。

### 2.4 风格

- 统一的间距与对齐，数字等宽；少用文字按钮，播放、录制等常用按钮用简洁的图形，由绘制接口画出，不依赖图标字体。
- 颜色：
  - 录制与超限用红色；
  - 填充条用当前主题的强调色；
  - 只读与次要信息用灰色。
- 不增加多余的装饰，深浅两种主题下都清楚。

## 3. 测试（预计）

- **查看器自检：**
  - 工具栏的录制按钮可以开始、停止记录；
  - 时间轴标签页回放时，执行器面板的实测值等于记录中该时刻的关节状态；
  - 拖动执行器控件后，目标进入下一步的控制量；
  - 新标签页出现在默认布局的底部组中。
- **纯逻辑：**由记录求某一时刻的控制量；每类执行器的实测量与归一化。
- **参考图：**不新增。界面元素不进入渲染参考图，自检中只检查数值。

## 5. 实现（2026-11-24）

代码已写，按约定未在开发机编译；验证脚本 `scripts/verify/m3_07d.sh`。

### 5.1 改动

| 部分 | 内容 |
| --- | --- |
| 视口工具栏 | 播放 / 暂停、单步、重置改为图形按钮（绘制接口画出，悬停显示名称与快捷键）；倍速下拉；红色圆点为录制按钮，录制中变为红色方块，旁边显示录制时长与文件大小；右侧为状态与 mm:ss.ss 时间。回放时同一组按钮控制回放 |
| 快捷键 | 固定 `Ctrl+Shift+R` 开始 / 停止记录（修饰键须完全一致，不会与 `Ctrl+R` 重置同时触发）；偏好设置“按键”页的“仿真：开始 / 停止记录”可另配单键（命令 `sim.record`，默认不绑定）；菜单“仿真”中的同名项显示该快捷键 |
| 时间轴标签页 `###Timeline` | 第一行：与工具栏相同的播放控制和录制按钮、“实时 \| 回放”两段式切换、右侧时间（回放时为“当前 / 总长”与文件名）。第二行：时间刻度——主刻度带时间标签（按宽度自动选 0.01 s～1 h 的间隔）、次刻度、轨道、播放头；实时模式下录制区段为红色；回放模式下刻度即记录的范围，轨道高亮记录区段，事件（如 error）为小三角，可在刻度上按下或拖动播放头。下面是记录列表：默认只列当前场景，可勾选“全部场景”，“重新扫描”，双击或点行尾 ▶ 回放，正在回放的记录高亮；时间显示为本地时间，结果显示为中文 |
| 停靠 | 默认布局中与日志、统计同组；已保存的布局中没有这个标签页时，首次显示并入日志（或统计）所在的组。菜单“文件 → 实验记录…”切到这个标签页；“窗口”菜单可开关 |
| 执行器面板 | 每个执行器两行：名字、类型与单位、右侧“实测 → 目标”；下面是控件——填充条为实测（从 0 或范围下限起），竖线为目标。实测按类型：位置执行器与 PD 层取关节位置，速度执行器取关节速度，力矩执行器取输出（除以增益，与控制量同一单位），其他取目标。超出范围时填充条与数字为红色。在条上按下或拖动设置目标，双击输入精确值；悬停显示全名、实测、目标、范围、输出力、传动比。顶部按名字过滤；按模型实例折叠 |
| 回放同步 | 回放时实测取记录中的关节状态（落在采样点上时就是该份状态，否则在相邻两份之间线性插值），目标取记录中该时刻生效的控制量（`controlsAt`：第 s 步的状态对应第 s−1 步之前下发的控制量）；PD 层接管的执行器没有记录目标，不画竖线。动作播放与回放时只读，竖线为灰色 |
| 移除 | 单独的“实验记录”与“回放”窗口 |

**说明：**
- 记录中的状态不含执行器输出，回放时力矩执行器的实测显示为目标。
- 字体中的数字不是等宽的；数字靠右对齐，以减少跳动。

### 5.2 测试

| 测试 | 内容 |
| --- | --- |
| `record.file`（扩充） | `controlsAt`：某一步生效的控制量（只在变化时记录，取步序号 ≤ s 的最后一次）、第 0 步、空记录 |
| `graphics.viewer_record_selftest`（扩充） | 开始与停止都按工具栏上的录制按钮（与点击同一路径）；回放到记录中间的一份状态时，执行器面板 4 个执行器的实测与目标逐位等于记录中的值，且面板对应的步序号正确；时间轴的记录列表中有刚保存的记录；时间轴与日志停靠在同一组 |

**变异（6 个）：**
- 录制按钮不开始记录；
- 回放时面板用实时状态；
- 回放时目标不取记录中的控制量；
- 回放步序号偏一步；
- 时间轴不在底部组；
- `controlsAt` 取到之后一步的控制量。

**未自动化：**
- 按键本身（`Ctrl+Shift+R`、可配置的单键）与鼠标拖动，在第 7 步的可见窗口中手动确认；
- 已保存的旧布局中首次并入日志组的路径，自检只覆盖默认布局。

### 5.3 基线机器结果

**第一次运行（2026-11-24）：未通过，编译错误，已修正。**
- 渲染关闭 73/73 通过；渲染开启的三种构建失败，变异只判定了 `controlsAt` 一项（1/6，其余编译失败）。
- 原因一：ImGui 1.93 已去掉 `GetWindowContentRegionMax`。改为由光标位置加剩余宽度求内容区右边界，新增 `sameLineRight` 统一处理靠右放置。
- 原因二：自检中的局部变量 `same` 遮蔽了外层同名变量（-Wshadow），已改名。

**第二次运行（2026-11-24）：自动测试全部通过，展示中点击“停止录制”崩溃，已修正。**
- 73/73、102/102（Debug 与 Release -Werror），ASan 81/81 + 21/21，变异 6/6；自检 13 项全部 PASS（含执行器面板与记录逐位一致、时间轴与日志同组）。
- 用户在可见窗口中点击工具栏的停止录制，程序段错误退出（139）。原因：录制按钮按下前记下了“正在录制”，按下后记录已结束、`recorder` 已释放，同一帧仍按旧状态读取录制大小（空指针）。自检直接调用切换函数，没有经过按钮之后的绘制，因此没有发现。
- 修正：按下后按当前状态显示。自检改为在工具栏上“按”录制按钮（与点击走同一条路径，包括按下后同一帧的绘制），开始与停止都经过按钮。
- 变异名“开始 / 停止切换不开始记录”中的斜杠使脚本统计失败项的 sed 报错（只影响计数），改名为“录制按钮不开始记录”。

**第三次运行（2026-11-24）：全部通过。**
- 渲染关闭 73/73；渲染开启 Debug 与 Release -Werror 102/102；ASan 81/81 + 21/21；变异 6/6（每个 1 项检查失败）。
- 自检 13 项全部 PASS：工具栏录制按钮开始并停止记录、停止后同一帧绘制正常；回放到第 70 步时 4 个执行器的实测与目标与记录逐位相同；时间轴列表中有新记录；时间轴与日志同组。
- 可交互展示退出码 0（125.7 秒）：用户从 G1 悬挂场景切到 Go2，录制约 19.6 秒（981 份状态）后停止，再从时间轴回放，没有崩溃。
