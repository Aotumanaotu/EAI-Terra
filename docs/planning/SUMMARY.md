## 1. M1 交付内容

| 类别 | 实际交付 | 当前边界 |
| --- | --- | --- |
| 图形环境与依赖 | 选定 OpenGL 4.5 core（D-021）；自动化图形测试固定为 Xvfb + Mesa llvmpipe（D-022）。以下依赖按版本与 SHA-256 锁定，获取都通过显式脚本，CMake 不自动联网：GLFW 3.5.1、GLM 1.0.3、glad 2.0.8、Dear ImGui 1.93.0-docking、nlohmann/json 3.12.0、stb、cgltf 1.15 | 只验证了 Ubuntu 22.04 / x86-64 / X11 桌面 |
| 平台与输入 | `terra_platform`：GLFW 私有后端，提供窗口、上下文、显示模式（窗口 / 无边框全屏 / 独占全屏，F11）与垂直同步。`terra_input`：动作映射、组合键与修饰键、死区、热插拔、多来源优先级仲裁 | 手柄适配器（M1-05，P1）后置 |
| 渲染 | `terra_render`：资源 RAII、着色器诊断、离屏渲染与像素回读。光照与材质：自研 PBR（参考 Filament 的公开文档，D-027）、太阳光与阴影（PCF）、基于 HDRI 的环境光照（漫反射与镜面）；可从环境贴图提取太阳。画面：4× MSAA，色调映射默认 AgX，另有 PBR Neutral、ACES；着色器地面网格；GPU 分阶段计时 | 没有物体间遮蔽（GTAO）与反射探针，材质观感留到 M3 改进 |
| 资产 | `terra_asset`：glTF 2.0 加载（cgltf），单位与轴向换算（Y 向上 → Z 向上）、5 种贴图、切线、双面材质、ARM 遮蔽约定，缺失资源给出诊断 | 尚未与物理实体绑定（M2） |
| 界面与设置 | `terra_ui` 与 `terra_viewer`：深色停靠式界面、中英文（Noto Sans SC 子集）、界面缩放、视口导航坐标系、组合式相机（中键转视角、Shift+中键平移、键盘移动、滚轮拉近）。`terra_settings`：JSON 设置（XDG 路径），按键、相机、显示、渲染参数都可修改并持久保存；统计面板含性能图表（帧时间、CPU、显存、进程内存） | 查看器显示的是固定的演示场景，还不运行物理 |
| 测试与基线 | 测试数：渲染关闭 39 项、渲染开启 57 项；3 张参考图（逐像素比较）；帧耗时基准程序；71 个变异测试；统一验收脚本 `m1_acceptance.sh` | 像素基准只在 llvmpipe 上成立 |

## 2. 关键验证结论（M1 统一验收）

- **一致性：**变异锚点 71/71 唯一。
- **M0 回归：**全部通过。
- **测试：**渲染关闭 **39/39**；渲染开启 Debug、Release + `-Werror` 均 **57/57**；ASan/UBSan 非图形 46 项、图形 11 项全部通过；57 项每项重复 3 次也全部通过。
- **变异测试：**M1 **60/60** 被发现，连同 M0 共 71/71。
- **依赖边界：**Headless 不链接图形库；渲染程序不链接 MuJoCo；渲染侧 9 个模块对物理模块的引用为 0。
- **参考图：**三张都逐像素一致。
- **帧耗时：**RTX 5060，GPU 中位数：1080p 默认画质 0.38 ms，4K 默认画质 1.30 ms，4K 无 MSAA 0.81 ms。这些数据只代表当前的小场景，不构成性能承诺。
- **真实 GPU：**自检通过；可交互展示约 60 FPS（垂直同步）。

详见 [M1-11 验收报告](../validation/M1-11-acceptance.md)；各任务报告在 [`docs/validation/`](../validation/)。

## 5. 保留风险与边界

- 渲染与物理尚未连接，查看器显示的是 M1 演示场景。
- 材质观感与 UE5/Blender 仍有差距；GTAO 等改进放在 M3，D-027 的后备方案是重新评估 Filament。
- MuJoCo 致命错误仍会终止宿主进程，由 M2-02 处理。
- M0 容差只适用于 MuJoCo 4.0.1、Euler 积分器和当前夹具；升级或换积分器需要重新评审。
- 像素基准依赖 Mesa 23.2.1 llvmpipe，升级 Mesa 后需要重新生成参考图。
- 项目许可证（D-109）待定；CI 未接入。
