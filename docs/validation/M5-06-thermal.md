## 1. 用户能做什么

- **设置温度：**在场景文件中写 `thermal` 段：
  - 环境温度、天空温度；
  - 按实体全名、实例名、以 `*` 结尾的前缀或 `world`（静态几何体）指定温度；
  - 温度可以写成随时间变化的曲线 `[[t, T], …]`；
  - 在实体上加热点：中心、半径、温度。
- **装热像仪：**相机写 `thermal`，选预设即可：
  - FLIR Lepton 3.5；
  - FLIR Boson 640 50°；
  - 海康 HM-TD5567T-15。

  可选的设置：增益档、色板（ironbow、white-hot、black-hot、rainbow）、显示区间（`auto` 或固定）、噪声。热像仪可以不输出彩色与深度。
- **查看：**查看器传感器面板的“相机”中显示伪彩色热像，以及最低、中心、最高温度；鼠标悬停显示该像素的温度。
- **采集：**`terra_capture` 写 `thermal/<步>.npy`（float32，°C）与 `thermal/<步>.png`（伪彩色）。
- **ROS2：**每台热像仪发布三个话题：
  - `<相机>/thermal/image_raw`：mono16，0.01 K；
  - `<相机>/thermal/image_color`：rgb8；
  - `<相机>/thermal/camera_info`。

示例：

```json
"thermal": {
  "ambient": 22, "sky": -20,
  "temperatures": {"world": 15, "go2/*": 35, "sub/transformer_1": [[0, 40], [600, 75]]},
  "hotspots": [{"entity": "sub/transformer_1", "position": [0.4, 0, 1.2], "radius": 0.15, "temperature": 110}]
},
"sensors": [
  {"type": "camera", "name": "go2/thermal", "entity": "go2/base", "position": [0.3, 0, 0.1], "rotation": {"rpyDeg": [90, 0, -90]},
   "rgb": false, "depth": false, "thermal": {"preset": "flir_lepton_3_5", "palette": "ironbow"}}
]
```

## 2. 模型

| 项 | 做法 | 依据 |
| --- | --- | --- |
| 温度来源 | 每个像素取所见表面的温度。优先级：热点 → 实体（匹配等级：实体全名 > 实例名 > 最长的前缀）→ 环境温度。<br>分割为 0 且有命中：静态几何体（`world`）；没有命中：天空温度 | 设计稿 3.1 节 |
| 计算方式 | 用同一帧的分割图（实体 ID）与线性深度在 CPU 上算出，与彩色、深度、分割像素对齐，不改着色器。<br>热点要表面位置：由深度与内参反投影，再变换到实体坐标系 | 分割通道（M4-09） |
| 热点 | 温度 = 底温 + (热点温度 − 底温) × (1 − (d / r)²)²：中心为热点温度，到半径处平滑地回到底温；多个热点取最高 | — |
| 时间曲线 | 按仿真时间线性插值，两端外延为常数 | 设计稿 2.1 节 |
| 噪声 | 时间噪声：每帧每像素 σ = NETD 的高斯。<br>固定偏差：每台相机一个，g × max(精度绝对值, 精度比例 × \|T\|) ÷ 2，精度按 2σ 理解，g 按种子取。<br>可关闭，与 M4-09 相同 | 数据手册 |
| 辐射测温 | round((T + 273.15) × 100)，T 先截断到所选增益档的量程 | FLIR Lepton TLinear 0.01 K |
| 伪彩色 | `auto` 时按每帧的最低、最高温度（不足 1 °C 时扩到 1 °C），否则按固定区间 | 设计稿 3.2 节 |
| 预设 | 分辨率、水平视场角（竖直视场角按方形像素算出）、帧率、NETD、增益档的量程与精度。<br>见 `assets/sensors/thermal_presets.json` 与设计稿 3.3 节 | Lepton 3.5 数据手册（2025-12）、Boson 640 产品页、海康产品页 |

**与设计稿的差别：**
1. **按 glTF 节点或材质的温度**放到 M5-02 元素中实现：元素做好后成为模型实例与实体，接到同一张温度表。目前按实体（MJCF body）、实例与前缀匹配。
2. **8 位灰度**不另出一路：white-hot 色板即灰度。
3. **实验记录**只记相机帧的元数据（与 M4-07 相同），不保存热像图像。

**不模拟（设计稿 3.1 节）：**
- 发射率与反射；
- 大气衰减；
- 热传导与热辐射；
- 镜头渐晕；
- 非均匀校正（NUC）的快门冻结。

设备的温升由开发计划 12.5 节的热网络求解器在 M5 之后给出。

## 3. 测试

| 测试 | 内容 |
| --- | --- |
| `simulation.thermal` | 不需要图形：<br>- 预设：Lepton 的 160 × 120、竖直视场角、8.7 Hz、量程、精度与 NETD；<br>- 匹配等级、曲线、热点；<br>- 10 种错误；<br>- 温度图中的天空、世界、实体、环境；<br>- 热点的中心与权重（按反投影）；<br>- 辐射测温与截断、色板端点、显示区间；<br>- 噪声：σ = NETD（3% 以内），固定偏差各帧相同且不为 0，同一步逐位相同，关闭时为真值 |
| `graphics.capture_thermal` | `terra_capture` 三次运行：<br>- 温度与分割、深度逐像素对齐（天空、墙、板、方块按曲线、加热器）；<br>- 热点最高 115～120 °C，位置与投影相差不到 2 像素；<br>- 背向墙全是天空温度；<br>- 噪声 σ ≈ NETD；<br>- 两次逐字节相同；<br>- `--no-noise` |
| `graphics.viewer_thermal_selftest` | 查看器：三台热像仪的温度图与预览纹理；图像中心 80 °C；背向墙为天空温度；没有 GL 错误 |
| `ros2.thermal` | 查看器开启桥接：<br>- mono16，中心 35315，即 80 °C；<br>- 天空截断到量程下限：26315；<br>- rgb8、camera_info（同一步）；<br>- 关闭 rgb 的热像仪没有彩色话题 |

**夹具** `assets/tests/sensors/thermal_bench.*`：墙 15 °C、板 80 °C、方块 20 → 60 °C、加热器 40 °C 带 120 °C 的热点；三台 Lepton 3.5（无噪声、有噪声、背向墙）。

**变异（7 个）：**
1. 热点不生效；
2. 天空当作世界；
3. 辐射测温不加 273.15；
4. 曲线不插值；
5. 温度匹配不按等级；
6. 热像没有固定偏差；
7. 温度图不跟随仿真时间（由 `graphics.capture_thermal` 发现）。
