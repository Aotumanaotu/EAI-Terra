# M1-07 相机与视口相机控制器

> 状态：**待验收**。`terra_view`：透视相机与**单一组合式**视口相机控制器；测试 `view.camera` 与可交互展示。基线机器（2026-11-19）全部通过：渲染关闭 37/37，渲染开启 Debug 与 Release + `-Werror` 43/43，ASan 全部通过，变异 5/5；用户在桌面试用 43 秒后确认操作手感没有问题（第 6.3 节）。

## 1. 依据与修订过程

- 开发计划 M1-07；PRD F-M1-01、F-M1-04、F-M1-06；D-018（只消费 Terra 输入动作）；D-020（GLM 只在 Render 与视图层内部）；D-012（Z 向上、+Y 向左）。
- **第一版（2026-11-19）**：环绕式与自由飞行式两套控制器，Tab 临时切换（计划在设置中切换）。第一次基线运行因测试中未使用的辅助函数触发 `-Wunused-function`，在 `-Werror` 配置下构建失败（LOG-037），修复后用户在桌面试用。
- **用户反馈与修订（D-023 修订）**：纯鼠标的环绕操作不顺手；改为**类似游戏的键鼠组合、不区分模式**：键盘只负责移动，鼠标与滚轮调整方向与远近。用户进一步确定：按住**右键**拖动转视角（松开时鼠标留给界面，左键留给以后的选择/拖动）；键盘前后**沿视线方向**（飞行式）。第一版的两套控制器已删除。

## 2. 接口（`engine/view/include/terra/view/`）

| 类型 | 说明 |
| --- | --- |
| `Camera`（`camera.hpp`） | 位置 + 偏航 + 俯仰（无滚转）；俯仰限制 ±89°，偏航归一化到 (-π, π]；`forward/right/up` 正交单位向量（right 水平）；`lookAt`；`viewMatrix()`、`projectionMatrix(aspect)` 输出列主序 `float[16]`（OpenGL 裁剪空间）。竖直视场 60° |
| `CameraController`（`camera_controller.hpp`） | 组合式控制，注册动作表 `camera`：见下表；`reset` 恢复默认视角（从 (-5, 0, 2) 看向原点）；`setEnabled`；`settings()` 可调参数；同一个 `InputSystem` 上只能有一个（重复注册抛出 `std::logic_error`） |

| 操作 | 默认绑定 | 默认参数 |
| --- | --- | --- |
| 转视角 | 按住右键拖动（向右 → 右转，向下 → 低头） | 0.15°/像素 |
| 前进 / 后退 | W/↑、S/↓，沿视线方向（含俯仰） | 3 m/s |
| 左 / 右平移 | A/←、D/→，水平方向 | 3 m/s |
| 上升 / 下降 | E/空格、Q/Ctrl，沿世界 Z | 3 m/s |
| 拉近 / 拉远 | 滚轮，沿视线方向 | 每格 0.5 m |
| 平移 | 按住中键拖动（场景跟随鼠标） | 0.01 m/像素 |
| 加速 | 按住 Shift（左右均可），作用于以上所有移动 | ×3 |
| 复位 | F | — |

默认绑定与参数只是初始值，之后由设置覆盖（D-026，M1-14）。方向如需反过来，只在绑定上加 `Processor::scale(-1)`，不改控制器代码。

## 3. 模块与依赖

`terra_view`（`engine/view/`，仅渲染开启）：PUBLIC `terra::input`、`terra::data`；PRIVATE `terra::glm`。不依赖 `terra_render` 与平台层，不包含窗口库或 OpenGL 头文件（`boundary.render_isolation` 覆盖 `engine/`）。

同时补充：`RenderContext::drawLines`（网格与坐标轴）；`Window::setTitle`。

## 4. 测试

**`view.camera`**（渲染开启时运行；自动化部分不需要显示；渲染开启共 43 项）：

| 用例 | 内容 |
| --- | --- |
| 相机数学 | 默认朝向原点；12 组朝向下基向量正交归一、right 水平、up 朝上；yaw 0 时前 +X、右 -Y、上 +Z；俯仰限制与偏航归一化；看向自身不产生 NaN；视图矩阵；投影（注视点居中，+Y 在左、+Z 在上，近/远平面 → z = ∓1） |
| 控制器 | 不按键拖动、左键拖动都不转视角；右键向右下拖 20 像素 → 偏航与俯仰各 −3°、位置不变；W/↑/↓ 沿视线（含俯仰）；D/← 水平；E/空格/Ctrl/Q 沿世界 Z；W + D 叠加；Shift ×3；滚轮上 1 格前进 0.5 m、下 2 格后退 1 m；中键平移两个方向；F 复位；停用后不响应；第二个控制器被拒绝 |

**可交互展示**：`test_view --show <秒>` 打开 1280×720 窗口，深灰背景，XY 平面 20 m × 20 m 地面网格（每 5 m 稍亮）、X 红 / Y 绿 / Z 蓝坐标轴、1 m 彩色立方体；标题栏与终端显示操作说明；Esc 退出。这也是 M1-04 留下的真实键鼠人工检查。

**变异测试（5 项）**：转视角不需要按右键；前进不含俯仰；滚轮方向反了；加速无效；方向键未绑定。
