# M2-08 查看器仿真模式

> 状态：**已实现，未编译（按约定），基线验证未执行**。依据：开发计划 9.2 节 M2-08（PRD F-M2-02、F-M2-03）。界面方案经用户 2026-11-23 确认：
> ① 打开场景用程序内的文件浏览窗口，并提供“最近打开”；② 视口上方放工具栏，状态栏显示仿真信息，快捷键为空格、句号、Ctrl+R；③ 打开场景后先暂停；④ 大纲 + 只读属性 + 视口高亮，视口点选留到 M5。

## 1. 交付

| 部分 | 内容 |
| --- | --- |
| 打开与关闭场景 | “文件 → 打开场景…”（Ctrl+O）弹出程序内文件浏览窗口：可编辑路径、上一级、目录与文件列表、双击进入或确认、只显示 `.terra-scene.json`（可切换为所有 `.json`）。另有“最近打开”（保存在设置中，最多 8 个、去重、最新在前）与“关闭场景”。打开失败时保留当前场景，弹窗列出全部诊断（带 JSON 指针），同时写入日志。打开 / 关闭在帧末处理，不在绘制界面的中途替换 GPU 资源 |
| 仿真控制 | 视口上方工具栏：播放 / 暂停、单步（暂停时可用）、重置、速度（0.25×–4×）。“仿真”菜单提供同样的操作。按键：空格播放 / 暂停、句号单步，均可在偏好设置的“按键”页修改；Ctrl+R 重置为固定快捷键，另可给“仿真：重置”分配单键。**打开场景后处于暂停**；`--demo-drive` 时直接运行 |
| 状态栏 | 运行状态（运行中 / 已暂停 / 故障），以及仿真时间、步数、实时因子（平滑后的仿真时间与墙钟时间之比）、过载次数 |
| 大纲 | 场景名 → 模型实例（含实体数）→ 实体（按父子层级）→ 视觉部件（几何体的形状与名字，被 glTF 隐藏的几何体标“-”；glTF 文件与节点）；每个实例另有“静态几何”分组。无名实体显示为“（无名）#ID” |
| 属性 | 选中实体的名称、模型实例、父实体、位置、姿态（滚转 / 俯仰 / 偏航，度）、线速度、角速度，取自最新快照，只读 |
| 选中高亮 | 选中实体的全部视觉部件（MJCF 几何体与 glTF）叠加一层暖色自发光 |
| 场景文件的显示设置 | `view.camera` 作为打开时的相机。`view.environment`（outdoor / studio / hemisphere）只作用于本次会话，不写入设置；在属性面板中手动换环境后不再沿用 |
| 演示资产 | 演示场景的三个 Poly Haven 资产只在显示演示场景时加载，打开场景文件时不再加载（M2-07 展示中发现的问题） |
| Headless `--scene` | 与 `--model` 二选一。组合场景中的模型实例后只跑物理，不读取视觉资源。场景错误以“场景错误 位置：原因”写到 stderr，退出码 4。输出格式不变，config 记录中多一个 `scene` 字段，实体名带实例前缀 |
| 设置版本 2 | 新增操作 `sim.playPause`（空格）、`sim.step`（句号）、`sim.reset`（默认不绑定单键），以及 `interface.recentScenes`。**版本 1 的迁移**：版本 1 的默认按键中，空格是 `camera.up` 的备用键；读入版本 1 文件且 `camera.up` 仍为默认值（E、空格）时，去掉其中的空格，使空格归播放 / 暂停，并给出一条提示。用户自己改过的不迁移，冲突时仍按“操作顺序在前者保留”处理。相机控制器自身的默认值同步改为只有 E |

新增演示场景 `assets/tests/scene/drop.terra-scene.json`（下落的方块）：地面、三个不同高度与姿态的方块（`cube.xml`）、一辆带 glTF 的小车，并自带摄影棚环境与相机位置。它不需要控制就能看到物理效果，可以用文件浏览窗口打开。
