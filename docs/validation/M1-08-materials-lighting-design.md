## 1. 目标观感

视口从“顶点色的预览场景”升级为接近 Blender Eevee / UE5 默认场景的观感：金属与粗糙度材质、太阳光与柔和环境光、实时阴影、色调映射与抗锯齿；地面网格与坐标轴保持编辑器风格。参数与 glTF 2.0 的金属度-粗糙度材质一致，为 M1-09 加载 glTF 资产与后续 MuJoCo 模型显示做准备。

## 2. 分两步交付

| 步骤 | 内容 | 需要的素材 |
| --- | --- | --- |
| **M1-08a 直接光照 PBR** | 程序生成网格（含法线）；PBR 材质；太阳光 + 半球环境光；方向光阴影；HDR 离屏渲染、曝光、色调映射、sRGB 输出；4× MSAA；着色器网格线 | 无 |

## 4. 着色模型（参考 Filament 文档的标准模型）

- 镜面：Cook-Torrance，GGX 法线分布，高度相关 Smith-GGX 可见性项，Schlick 菲涅耳；`α = roughness²`，粗糙度下限 0.045 防止高光闪烁。
- 漫反射：Lambert；金属度插值：`diffuse = baseColor·(1−metallic)`，`F0 = mix(0.16·reflectance², baseColor, metallic)`。
- 光照单位：太阳照度为相对值（默认 3.0），由单一曝光参数控制亮度；不引入物理相机（EV100）——留待 M3 画质评估时决定。
- 环境光（a 阶段）：半球光（按法线 Z 在天空色与地面色之间插值）× 漫反射，镜面部分用粗糙度近似；b 阶段替换为 IBL。

## 5. 颜色管线、抗锯齿与阴影

- **线性工作流**：材质颜色以线性值存储；着色在 RGBA16F 中进行；最后一步色调映射并编码为 sRGB 写入 RGBA8 视口纹理（ImGui 直接显示）。界面主题颜色不受影响。
- **色调映射（建议默认 AgX，可在设置中切换）**：AgX（Blender 4 默认，高光过渡自然）、Khronos PBR Neutral（基础色还原最准确，适合检查材质）、ACES（近似 UE 的电影感）、无（线性截断，仅调试）。曝光默认 0 EV，可调。
- **抗锯齿**：4× MSAA（可在设置中改为关 / 2× / 8×）。
- **阴影**：太阳光单张阴影图（2048²），按场景包围盒拟合正交投影；3×3 PCF 软化；坡度偏移防止“阴影痤疮”。级联阴影（大场景）留到 M2/M3。
- **网格线**：改为着色器绘制的无限地面网格（1 m / 10 m 两级，随距离淡出，X 轴红线、Y 轴绿线），与 Blender 视口相同的观感；Z 轴保留为短线段。

## 6. 视口演示场景

替换现有预览：地面平面（浅灰、粗糙）；“材质球”阵列——5×2 个球体，一行金属度 0→1、一行粗糙度 0→1；一个立方体、一个圆柱、一个胶囊；太阳光投下阴影。属性面板（Details）新增“渲染”分组：太阳方位角 / 高度角、强度、环境光强度、曝光、色调映射、MSAA、阴影开关——修改立即生效并写入设置文件（`render` 组，沿用 M1-14 机制）。

### 13.3 实现

| 位置 | 内容 |
| --- | --- |
| `terra/render/hdr_image.hpp` | `HdrImage`（线性 RGB，行 0 为天顶）、`loadHdr`、合成环境（纯色、上下两色、左右两色）、`equirectDirection`；等距柱状约定：u = 0.5 为 +X、u = 0.75 为 +Y |
| `terra/render/environment.hpp` | `Environment::create`：等距柱状 → 512² 环境立方体（含 mip）→ 16² 辐照度（余弦加权中点法 32 × 128）→ 128² × 6 级预过滤（GGX 重要性采样 64 样本，按概率密度选源 mip；第 0 级直接复制）；DFG 表 64² 在 CPU 上用 `pbr::dfgLut` 计算后上传；立方体方向即世界方向（按 OpenGL 面约定生成） |
| `terra/render/pbr.hpp` | `dfgLut`、`sampleDfg`（与 GL_LINEAR 一致）、`ambientIbl`：环境光 = 辐照度 · diffuseColor · (1 − E) + 预过滤 · E，E = F0 · A + B；对应 GLSL `ambientIbl` 与 `envDirection`（绕 Z 旋转） |
| `SceneRenderer` | 新增 `EnvironmentLighting`（环境、强度、旋转、背景、背景模糊）；有环境时环境光完全来自贴图（半球光不参与）；背景在不透明物体之后、网格之前以远平面全屏三角形绘制 |
| 设置 `render` 组 | 新增 `environment`（`outdoor` 默认 / `studio` / `hemisphere`）、`environmentIntensity` 0.6、`environmentRotationDegrees` 0、`environmentBackground` 开、`backgroundBlur` 0.25 |
| `terra_viewer` | 环境贴图首次选用时读取并预计算（失败只报告一次并改用半球光）；“渲染”分组新增环境选择、强度、旋转、背景与模糊；半球光强度只在半球光模式下可调 |
