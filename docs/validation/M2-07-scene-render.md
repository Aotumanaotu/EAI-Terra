# M2-07 场景帧与渲染接入

> 状态：**已实现并通过基线验证，已验收（M2-09，2026-11-23）**（2026-11-23 第二次运行全部通过，第 4 节）。依据：[M2-01 设计](M2-01-scene-design.md) 第 5、6 节；开发计划 9.2 节 M2-07、9.5 节第 4、7 条。

## 1. 交付

| 部分 | 内容 |
| --- | --- |
| `terra_asset`：节点表 | `Asset::nodes` 记录名字、父节点与 glTF 世界矩阵，实例记录所在节点。`findNode` 支持按名字或 `#下标` 查找：找不到时列出文件中的节点；名字重复时要求改用下标。另有 `inSubtree`、`bindingBase`、`subtreeTransforms`、`invertAffine`，以及 `GpuAsset::subtreeItems`。`Node` 对齐：模型矩阵 = 放置 × C × 节点世界⁻¹ × 实例世界；`Assembly` 对齐：模型矩阵 = 放置 × C × 实例世界（C 为 Y→Z 换算）。原有的整文件接口不变，M1 参考图不受影响 |
| `SceneView`（`apps/viewer/scene_view.*`，属于 `terra_viewer_scene`） | 把视觉部件与世界位姿转换为渲染项，详见下表 |
| 查看器 `--scene <文件>` | 组合物理世界并运行仿真（`SimulationRunner`），视口显示由快照驱动的场景，代替演示场景。场景文件中的 `view.camera` 作为初始相机。场景有错误时打印带位置的诊断，并以退出码 4 结束。退出时打印步数、仿真时间与过载次数 |
| 查看器 `--demo-drive` | 演示用：所有执行器施加正弦控制，幅度为控制范围的 60%，相位错开 |

**`SceneView` 的规则：**
- **MJCF 几何体**：同形状、同尺寸的几何体共用一个程序网格。椭球用单位球加缩放；MJCF 网格按平直着色上传。
- **颜色**：几何体颜色按 sRGB 换算为线性，粗糙度 0.55，非金属。alpha 小于 0.01 的几何体不显示，因为 MJCF 常用 alpha = 0 表示隐藏。
- **平面**：只接收阴影；尺寸为 0（无限大）时按 50 m 见方显示。
- **glTF 绑定**：每个文件只加载一次，按节点取子树。读不出文件或节点不存在时给出提示并放弃该绑定，实体改为显示 MJCF 几何体。
- **显示规则**：默认显示 group 0–2；实体只有“可用的”绑定且都没要求 `showGeoms` 时，才隐藏它的几何体；可以叠加显示碰撞几何体。

**边界：**开发计划 9.5 节第 7 条已确定由查看器直接扩展，因此从本步起，查看器程序链接 MuJoCo 后端。`terra_render`、`terra_ui`、`terra_asset`、`terra_viewer_scene` 仍然不链接物理库。M1 验收脚本中“渲染程序不链接 MuJoCo”这项检查相应改为只检查 `terra_render_bench`。

**夹具调整：**
- `cart.gltf` 改为两个带平移的根节点 `Chassis`、`Mast`，网格放在子节点 `ChassisBody`、`MastBody` 上并带缩放，用于区分 `node` 与 `assembly` 两种对齐。`Mast` 的装配位置与 cart_a 桅杆的初始位置重合。
- `cart.xml` 增加 alpha = 0 的几何体 `sensor_zone`。

M2-04～M2-06 的测试只依赖名字、数量与“同一文件两次加载”的比较，不受这些调整影响。
