# M3-07c 查看器的实验记录与回放

> 状态：**已实现并通过基线验证**（2026-11-24，第 3 节）；用户对交互提出改进意见，另起 M3-07d。依据：[M3-07 设计稿](M3-07-record-design.md) 评审问题 2（默认 50 Hz，客户端可设置）、问题 4（带时间轴的回放）。

## 1. 交付

**记录（菜单“仿真”）：**
- **开始记录：**先回到一个可复现的起点，再写记录头与第 0 步的状态：
  - 有动作时，从头播放动作，按其起始关键帧重置；动作没有起始关键帧时，先回到场景的初始状态；
  - 没有动作时，重置到场景的初始状态。
- **记录内容：**
  - 控制量来自 `SimulationRunner` 新增的**控制观察者**：每次 `setControl` 被接受后通知，包括排队的命令（面板、演示驱动）和每步控制器的输出（动作、PD 层）。
  - 状态由步观察者按采样间隔写出。
- **同一步多次下发：**记录器合并为一行，后下发的覆盖先下发的，与 MuJoCo 中最终的控制量一致。查看器中排队的命令与控制器输出会在同一步出现，所以需要合并；Headless 不受影响。
- **停止记录：**写摘要并加入资源库。**重置、按关键帧重置、重新开始动作、切换或关闭场景、开始回放时也会自动结束**（结束原因 `stopped`）；步进出错时记录 `error` 事件，结束原因为 `error`。一份记录对应一段连续运行。
- **文件位置：**资源库旁的 `records/<场景名>-<UTC 时间>.terra-record.jsonl`。
- **记录采样率：**子菜单中可选 10、25、50、100、250、500 Hz，默认 50，保存到设置的 `interface.recordSampleHz`（范围 1–1000；增加字段不改变设置文件的版本号）。步长 0.002 s、50 Hz 时为每 10 步采样一次。
- **状态栏：**记录时显示“● 记录中”与文件大小，回放时显示回放时间。

**实验记录窗口（文件 → 实验记录…）：**
- 列出资源库中的记录：时间、场景、动作、步数、时长、结果、大小；可勾选“只看当前场景”。
- “重新扫描”按记录目录重建索引；“回放”打开该记录。

**回放：**
- 读入记录。记录中的场景与当前不同时，先打开该场景；场景文件的 sha256 与记录时不同时，只在日志中警告。
- 回放期间不推进物理，画面由记录的状态给出：时刻正好落在采样点上时直接取该份状态，因此逐位相同；其余时刻在相邻两份之间插值，沿用 M2-06 的插值。
- 回放窗口：播放 / 暂停（空格键同样可用）、拖动时间轴、倍速（0.1–4×）、退出回放。

**命令行：**新增 `--library <库文件>`；自检用的 `--record-self-test`。

## 2. 测试

| 测试 | 内容 |
| --- | --- |
| `graphics.viewer_record_selftest`（新增） | 机械臂场景 + `arm_swing`：第 3 帧打开动作，第 6 帧开始记录，中间停止并回放，再跳到记录中间的一份状态。**检查：**<br>• 记录可读回且完整（结束原因 stopped）；<br>• 默认每 10 步采样一次；<br>• 从动作的起始关键帧 `arm/rest` 开始；<br>• **查看器中记录的运行可以复现，所有采样点逐位相同**；<br>• 已加入资源库（构建目录中的库文件）；<br>• 回放到该状态时画面位姿与记录逐位相同；<br>• 没有 GL 错误 |
| `record.file`（扩充） | 同一步两次下发合并为一行，后下发的覆盖先下发的，没有变化的执行器不写 |
| `settings.store`（扩充） | 记录采样率：默认 50、往返、超出范围时用默认值并警告 |

**测试总数：**渲染关闭 73（不变），渲染开启 101 → **102**。

**变异测试 6 项**（`scripts/verify/m3_07c.sh`，支持 `--mutation-only`）：
- 记录器：同一步多次下发不合并；
- 查看器：记录头不写起始关键帧；不记录控制量；采样率设置不生效；
- 设置：采样率不写入设置文件；
- runner：每步控制器的命令不通知观察者。

M3-07a 脚本中“控制量不去重”的锚点随记录器的修改更新（合并后的去重在 `flush` 中）。

## 3. 验证记录

开发机：未编译、未运行（按约定）。已做的静态检查：
- 变异锚点全部唯一，所有脚本合计 191/191；
- 脚本通过 `bash -n`。

**基线机器（2026-11-24）：全部通过。**
- 测试：渲染关闭 **73/73**；渲染开启 Debug、Release + `-Werror` **102/102**；ASan 非图形 81/81、图形 21/21。
- 变异测试 **6/6**，各项发现的检查失败数为 2、2、2、1、1、2。
- 自检：记录 140 步（15 份状态、140 行控制量）；复现 15 个采样点逐位相同；已加入资源库；回放到第 70 步时画面逐位相同；没有 GL 错误。
- 展示：用户在 G1 悬挂场景记录 14.1 秒、在 Go2 场景记录 22.2 秒，都已回放；切换场景正常。

**用户意见（2026-11-24）：**功能逻辑没有问题，但交互需要改进：
1. “开始记录”藏得太深，每次开始、停止都要打开菜单，很麻烦；
2. 回放功能希望作为底部（日志、统计旁边）的一个标签页；
3. 回放时执行器面板没有跟着动，应当同步；
4. 执行器面板中“输出”和“控制”希望合为一个：输出在变化时，滑块也跟着动；
5. 整体风格更专业、美观，但保持简约。
