# M2-05 场景文件、场景实例与视觉部件

> 状态：**已实现并通过基线验证**（2026-11-23，第 5 节）。依据：[M2-01 设计](M2-01-scene-design.md) 第 3、4、6 节；开发计划 9.2 节 M2-05、9.5 节第 4 条（用户 2026-11-23：支持“MJCF 实体 → glTF 节点 → 局部变换”）。

## 1. 交付

`terra_scene` 新增以下接口（`terra/scene/scene.hpp`、`pose_math.hpp`）：

| 接口 | 说明 |
| --- | --- |
| `parseScene` / `readSceneFile` | 读取并校验场景文件，得到 `SceneDocument`，相对路径按场景文件所在目录展开 |
| `instantiate` / `loadScene` | 组合物理世界（M2-04），解析 glTF 绑定的实体，建立视觉部件表 |
| `visualPoses` / `entityPoses` | 由实体位姿（快照或插值结果）计算每个视觉部件的世界位姿，双精度 |
| `pose_math.hpp` | 位姿相乘与求逆、四元数旋转、`rpyDeg` → 四元数 |

nlohmann/json 只在 `scene_file.cpp` 中使用。`boundary.render_isolation` 的 JSON 允许目录增加了 `engine/scene/src/`。

## 2. 场景文件校验

按 [M2-01 设计](M2-01-scene-design.md) 3.2 节：
- `format` 必须是 `terra.scene`；`version` 为整数，高于 1 时报错并提示更新程序。
- **未知字段一律报错**，包括嵌套对象中的字段。
- 类型、个数、取值范围都检查：
  - 步长 > 0；
  - 积分器与求解器只能取已知名字；
  - 迭代次数在 1–1000000 之间；
  - 容差 ≥ 0；
  - 缩放 > 0；
  - `frame` 只能是 `node` 或 `assembly`；
  - `showGeoms` 为布尔值。
- 旋转只能写 `quat` 或 `rpyDeg` 其中一种：四元数长度为 0 时报错；不是单位长度时归一化并给出警告。
- 每条诊断都带 JSON 指针，例如 `/models/0/positon`、`/visuals/2/scale`。一次报出全部问题，不会在第一个错误处停下。

## 3. 视觉部件

**编号：**先排 MJCF 几何体（按 `GeomId`），再排 glTF 绑定（按场景文件顺序），`VisualId` 从 1 连续编号。

**glTF 绑定的处理：**
- 实体名必须是全名。找不到时：没带前缀的，提示正确写法；带了前缀的，列出该实例中的实体（最多 8 个）；前缀本身不存在的，说明没有这个实例。
- 实体、文件、节点三者都相同的视为重复绑定，报错，并指出与哪一条相同。同一实体可以绑定多个不同节点，即一个实体有多个视觉部件。
- glTF 文件不存在时只给警告，并忽略这条绑定，该实体改为显示 MJCF 几何体，物理仍可运行。
- 本模块不解析 glTF，节点是否存在在 M2-07 由查看器检查。

**隐藏规则：**实体只要有一条 glTF 绑定、且没有任何绑定写 `showGeoms: true`，它的 MJCF 几何体就默认隐藏。静态几何（如地面）不受 `world` 绑定影响。

**世界位姿：**
- 几何体：`T_实体 × T_局部`。
- glTF 绑定：`T_实体 × O × T_局部`，缩放 `scale` 单独给出，由渲染侧应用。其中：
  - `node` 对齐时 `O` 为单位变换；
  - `assembly` 对齐时 `O = T_实体(初始)⁻¹`：初始姿态下，整个装配保持 glTF 中的摆放；实体运动后，视觉部件随之刚性移动。
- 静态装饰（实体写 `world`）的 `T_实体` 为单位变换。

## 4. 夹具与测试

**新夹具**（`assets/tests/scene/`）：
- `two_carts.terra-scene.json`：地面 + 两辆小车；4 条绑定，分别覆盖 `node`、`assembly`、`showGeoms` 加局部偏移、静态装饰；另有 `physics` 与 `view`。
- `cart.gltf`：本项目生成的极小 glTF。一个立方体网格、两个节点 `Chassis` 与 `Mast`，数据内嵌在文件中，M2-07 也会用到。
- `cart.xml` 新增几何体 `bumper`，相对车身有偏移，用于检验几何体的局部位姿。M2-04 的测试不受影响：实体数与无名几何体数不变，逐位相同的比较两边加载的是同一个文件。

| 测试 | 内容 |
| --- | --- |
| `scene.file`（新增，纯逻辑） | 夹具的全部字段与路径展开；`rpyDeg` 的旋转顺序；非单位四元数的警告；30 个错误用例的 JSON 指针与原因；一次报出多个错误；文件不存在。另带 `--diagnose <文件>` 演示模式 |
| `scene.instance`（新增，使用 MuJoCo） | 视觉部件的编号与顺序；归属；隐藏规则；初始世界位姿（几何体、node、带偏移与放置旋转的绑定、assembly、静态装饰、偏航 90° 后的保险杠）；推动小车后，node 对齐的绑定随车身移动、assembly 对齐的整体平移；各类诊断 |

测试总数：渲染关闭 42 → **44**，渲染开启 60 → **62**。

变异测试 8 项（`scripts/verify/m2_05.sh`）：
- 场景文件：未知字段不报错、`rpyDeg` 顺序颠倒、版本不检查上限、相对路径不按场景目录展开；
- 视觉部件：`assembly` 对齐未补偿初始位姿、`showGeoms` 被忽略、几何体局部位姿未应用、重复绑定不检查。

脚本第 6 步用 `--diagnose` 打印一个故意写错的场景文件的全部诊断，供你查看诊断的写法。
