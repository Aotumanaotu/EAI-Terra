# M4-08c 资源库与一键打开的场景卡片：实现报告

> 状态：**通过**（2026-11-25，第二次基线运行）。设计见 [M4-08c 设计稿](M4-08c-library-design.md)（评审通过；用户修正：场景就是按钮，点一下就加载）。
> 验证脚本：`bash scripts/verify/m4_08c.sh`（同时复跑 M4-08b 的全部测试）。

## 1. 用户看到的变化

| 位置 | 变化 |
| --- | --- |
| 资源库面板（新，左侧上方；左侧栏 17% → 20%） | 全部场景都是卡片，**单击即加载**。<br>分页：场景、动作（单击即打开推荐场景并播放）、机器人（打开用到它的场景）。<br>筛选：全部、收藏、最近、内置、导入；还有搜索框和网格 / 列表切换。<br>卡片上有：矢量图标、短标题、说明、标签（来源、IMU / 相机 / 雷达、PD、悬挂、动作数）。<br>当前场景描边并标“当前”；右上角星标收藏；右键菜单：收藏、复制路径、在文件管理器中显示、按配方重新导入、导出资产包、隐藏 |
| 欢迎页（没有打开场景时，视口中） | 大号场景卡片，收藏与最近打开的排在前面；右上角 × 可关闭（本次会话） |
| `Ctrl+P` / 文件 → 快速打开 | 搜索框：输入名字的一部分，↑↓ 选择，回车打开（场景与动作） |

| 偏好设置 → 界面 → 资源库 | 资源库位置（目录）；“使用这个位置”、“复制到新位置”、“恢复默认位置” |
| 模型文件还没下载的场景 | 卡片变灰并带感叹号，悬停提示运行 `scripts/assets/fetch_robots.sh` |

## 2. 实现

| 部分 | 文件 | 说明 |
| --- | --- | --- |
| 资产表 | `engine/library/{include/terra/library/library.hpp,src/library.cpp}` | 库版本 1 → 2（打开旧库时加表，记录不变）。<br>`scanAssets`：增量扫描（修改时间与大小不变就跳过解析；依赖缺失文件的条目每次重新解析）；不再存在的标为缺失，不删除登记，收藏与隐藏保留。<br>机器人由场景用到的 MJCF 推出（只算有关节或执行器的）。<br>其他：`setFavorite`、`setHidden`、`relocate`、`copyLibrary`（`VACUUM INTO` 与目录复制）、`assetMatches`、`defaultScanRoots`；`":memory:"` 表示内存中的临时库 |
| 资产包 | `engine/library/{include/terra/library/pack.hpp,src/pack.cpp}`、`third_party/miniz/` | zip 加 `manifest.json`；导出可重复（排序、固定时间戳）。<br>解包时拒绝不安全路径与清单之外的条目，核对 sha256；先解到隐藏的临时目录，成功后再改名 |
| 场景短标题 | `engine/scene`、9 个内置场景、导入器与配方 | 新增可选字段 `title`；导入生成的场景写入 `title`（配方的 `title`，没有时为实例名）；TurtleBot 4 的配方为 “TurtleBot 4” |
| 查看器 | `apps/viewer/library_panel.{hpp,cpp}`、`main.cpp`、`viewer_settings.*` | 面板、欢迎页、快速打开、菜单、资源库位置、导入后登记、资产包；`--library-self-test` |
| 不在用户目录中建库 | `main.cpp` | 资源库文件不存在时，卡片来自内存中的临时库；第一次收藏、保存记录或导入时才建立库文件。<br>自检（`--self-test`）没有给 `--library` 时只用内存，不读写用户目录 |
| 命令行 | `apps/headless`、`apps/import` | `terra_headless --list-assets [--kind …]`：没有库文件时只在内存中扫描。<br>`terra_import --library`：导入后登记；`--export-pack`、`--import-pack` |
| 设置 | `engine/settings` | `interface.libraryLocation`（空为默认；命令行 `--library` 优先） |

| `graphics.viewer_import_selftest`（扩充） | 导入后已登记（来源为导入，标题为实例名） |

**变异测试（8 个）：**
- 增量扫描不跳过未改动的文件；
- 删除的文件不标为缺失；
- 重新扫描清掉收藏；
- 搜索只看第一个词；
- 资产包接受含 `..` 的路径；
- 资产包不核对 sha256；
- 单击卡片不打开场景；
- 命令行导入后不登记。

**预期：**渲染关闭 99/99，渲染开启 135/135，含 ROS2 147/147。

## 4. 基线结果

**第一次运行：**渲染构建有 3 处编译错误，渲染关闭 Debug 99/99 已通过。
- ImGui 1.92.8 起 `AddRect` 的 `thickness` 与 `flags` 换了位置，旧签名被删除；
- 设置窗口中的变量 `current` 与同一函数中的变量重名（`-Wshadow`）；
- 自检的一行输出少一个 `%zu` 参数。

三处修正后第二次运行**全部通过**：

| 项 | 结果 |
| --- | --- |
| 渲染关闭 Debug | 99/99 |
| 渲染 Debug、Release -Werror | 135/135、135/135 |
| ASan 非图形 / 图形 | 108/108、27/27 |
| 含 ROS2 Release -Werror | 147/147 |
| ASan 含 ROS2 | 12/12 |
| 变异 | 8/8 |
| 第三方校验 | 12/12（含 miniz） |

**关键输出：**
- 资源库扫描：展示时第一次 16 个文件、39.9 ms（全部解析）；再次扫描 4.5 ms（全部跳过）；
- `import.cli_pack`：解包后 10 个文件逐字节相同；
- 查看器自检：欢迎页与面板各 13 张卡片（内置 9 个、测试夹具 4 个），单击、高亮、收藏、快速打开、动作播放、隐藏全部通过；
- 导入向导自检：导入后已登记（来源为导入）；
- TurtleBot 4 重新导入（场景带短标题），3 个 Collada 警告与 M4-08b 相同；
- 展示中依次单击打开了 10 个场景（TurtleBot 4、G1、AS2、Go2、Go2W、Stretch 3 等）。

## 5. 用户验收意见（2026-11-25）

- **卡片的方式是对的。**具体交互“还差点什么”，值得继续推敲，**放到后期的界面优化**（记入开发计划的待办，本步不再改）。
- **TurtleBot 4 的外观：**用户确认没有问题。M4-08b 遗留的 3 个 Collada 节点变换警告（Create 3 的底盘与保险杠）按 assimp 默认处理的结果是对的，关闭。
