## 2. 接口（`terra/platform/platform.hpp`，只用 Terra 类型）

| 新增 | 说明 |
| --- | --- |
| `DisplayMode` | `Windowed`、`BorderlessFullscreen`、`ExclusiveFullscreen`；`displayModeName()` 返回中文名称 |
| `VideoMode`、`MonitorInfo` | 视频模式（宽、高、刷新率）；显示器（序号、名称、是否主显示器、位置、缩放、当前模式、支持的模式列表） |
| `Platform::monitors()` | 已连接的显示器，第一个为主显示器 |
| `Window::displayMode()` / `setDisplayMode(mode, monitorIndex = -1, videoMode = 空)` | `monitorIndex < 0` 时取窗口当前所在的显示器（按重叠面积）；`videoMode` 只对独占全屏有效，必须是显示器支持的模式 |
| `Window::toggleBorderlessFullscreen()` | F11 语义：窗口 ↔ 无边框全屏；从独占全屏回到窗口 |
| `Window::setVsync(bool)` | 垂直同步开关 |
| `PlatformErrorKind::InvalidRequest` | 不存在的显示器、不支持的视频模式 |

## 3. GLFW 实现要点

- **无边框全屏**：显示器的当前桌面模式，即 GLFW 文档推荐的 windowed full screen；**不改变显示器分辨率**，切换快。
- **独占全屏**：使用请求的视频模式；请求的模式不在显示器支持列表中时**明确拒绝**，不让 GLFW 悄悄挑一个“最接近”的模式。
- **切回窗口**：恢复进入全屏前的位置与大小（从窗口进入全屏时保存）。
- **自动最小化**：只在独占全屏时开启（失去焦点时最小化，符合游戏习惯）；无边框全屏切到其他窗口时保持原样。
- 尺寸变化在 X11 下是异步的，可能在下一次 `pollEvents` 后才体现；应用每帧读取帧缓冲尺寸设置视口，画面不变形。

## 4. 测试

**`graphics.platform_display`**（Xvfb + llvmpipe，`graphics` 标签；渲染开启共 44 项）：显示器查询（至少一个、第一个为主、当前模式有效且在支持列表中）；640×480 窗口 → 无边框全屏（帧缓冲等于显示器尺寸）→ 切回窗口（恢复 640×480）；F11 语义往返；独占全屏（当前模式）后 F11 回到窗口；不存在的显示器与不支持的模式返回 `InvalidRequest` 且不改变当前模式；垂直同步开关。切换后轮询事件等待尺寸更新（最多 2 秒）。

**可交互展示**：沿用 M1-07 的视口展示，新增 **F11** 在窗口与无边框全屏之间切换；启动时打印真实显示器与支持的模式数。

**变异测试（3 项）**：切回窗口不恢复原尺寸；不校验独占模式；显示模式状态未更新。原第 4 项“全屏未使用显示器尺寸”是 Xvfb 下的**等价变异**（见 5.2 节），已移出自动列表，改由**真实显示器检查**覆盖：验证脚本在桌面会话中用真实显示器运行同一组显示模式检查。

| 项目 | 结果 |
| --- | --- |
| 渲染关闭 Debug | 37/37 通过 |
| 渲染开启 Debug / Release + `-Werror` | 均 **44/44 通过** |
| ASan/UBSan | 非图形 39 项、图形 5 项全部通过 |
| 变异测试 | **3/4**：切回窗口不恢复原尺寸（3 项失败）、不校验独占模式（2 项）、显示模式状态未更新（6 项）被发现；**“全屏未使用显示器尺寸”未被发现** |
| 可交互展示 | 真实显示器 DP-2（主），3840×2160@60Hz，支持 27 种模式；NVIDIA RTX 5060；用户按 F11 切到无边框全屏再切回窗口，操作 50.7 秒，退出码 0 |

测试输出：Xvfb 显示器 `screen`（主），1280×720@0Hz，**只支持 1 种模式**；不支持的模式 `12345x77@1Hz` 被拒绝。

**未被发现的变异是等价变异。**该变异把全屏请求的尺寸改为一半。GLFW 进入全屏时并不直接使用请求的尺寸，而是从显示器支持的模式中选最接近的一个，窗口按该模式定尺寸。Xvfb 只有 1280×720 一种模式，所以变异后仍得到 1280×720，与正确代码行为相同，在该环境中原则上无法区分。在有 27 种模式的真实显示器上，变异会把分辨率切到另一个模式（例如 1920×1080）。

**处理：**
1. 从自动变异列表移出（在 Xvfb 中运行只会永远报“未发现”），本节记录原因。
2. 新增**真实显示器检查**（验证脚本第 6 步）：桌面会话中用真实显示器运行同一组显示模式检查，确认无边框全屏后帧缓冲等于桌面模式（3840×2160）、切回窗口恢复原尺寸。正确代码不会改变显示器分辨率。
3. 不在桌面上运行该变异：它会真的切换用户显示器的分辨率，干扰过大。
